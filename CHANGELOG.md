# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [семантические](https://semver.org/lang/ru/).

## [4.8.0] — 2026-11-04

Роли администраторов: регистратор не открывает настройки, редактор не удаляет, наблюдатель только читает. Выпуск с GitHub Release.

### Добавлено

- **Роли администраторов** на основе `spatie/laravel-permission` ([документация](docs/roles.md)). Выключены по умолчанию (`fastleo.roles.enabled`), пакет нужен только сайтам с ролями. Действие разрешено, только если его разрешают роли, метод ресурса `can()` и Policy модели. Права называются `fastleo.{раздел}.{группа}` (просмотр, создание, изменение, удаление), живут под guard `fastleo` и не смешиваются с ролями сайта. Администратор без ролей ничего не может; если роли включены, а трейта `HasRoles` или таблиц нет, доступ закрыт.
- **Роль-владелец** (`fastleo.roles.owner`, по умолчанию `fastleo-owner`) проходит все проверки и единственная открывает «Администраторов», «Роли», настройки, свои страницы, файлы, журнал ошибок, очистку кеша, SoftNetica, закрытие сайта и виджет «Состояние сервера». Если сайт задал для них свой Gate или `canAccess()`, решает он.
- **Раздел «Роли»** с матрицей «раздел × просмотр / создание / изменение / удаление»: галочка на изменении или удалении ставит просмотр, снятие просмотра убирает остальное. Роль-владельца нельзя изменить или удалить.
- **Готовые роли** «Администратор», «Редактор» и «Наблюдатель» (`php artisan fastleo:roles --presets`); существующие роли команда не трогает. «Редактор» и «Наблюдатель» не получают разделы доставки сообщений (каналы, уведомления, публикации).
- **Поле «Роли»** у администратора (список галочек) и столбец «Роли» в списке администраторов.
- **Команда `fastleo:roles`:** создаёт роль-владелец, `--owner=email` выдаёт её администратору, `--presets` создаёт готовые роли.
- **Защита последнего владельца:** его нельзя удалить, лишить роли или доступа в админку, в том числе одновременными запросами двух администраторов.
- **Хук `Resource::beforeDelete(Model $record)`:** проверка перед удалением внутри транзакции (из раздела, из корзины и массового действия); `OperationCancelled` с причиной показывает её администратору ([документация](docs/authorization.md#проверка-перед-удалением-beforedelete)).
- **Закрытая связь:** поле `BelongsTo` / `BelongsToMany` на раздел, который роль не открывает, становится серым с подсказкой, а фильтр не отдаёт варианты.
- **Страницы ошибок 403, 404, 419 и 429** в стиле админки (в меню для вошедшего, на экране входа для гостя); JSON-запросы и страницы сайта не меняются. Шаблон подменяется через `vendor/fastleo/errors/page.blade.php` ([темы](docs/theming.md)).
- **`fastleo:inspect`, MCP `describe_resource` и `fastleo:doctor`** показывают права ролей и проверяют настройку (нет владельца, администраторы без ролей, режим teams, права, выданные напрямую).

## [4.7.5] — 2026-11-04

Выбор записи в блоках, поле `MorphTo`; журнал изменений убран из пакета. Выпуск без GitHub Release (только тег).

### Добавлено

- **Выбор записи в блоках `HasMany`/`HasOne`:** внутри блока теперь работает `BelongsTo` (товар в составе комплекта, услуга в записи). Так же описываются колонки связи «многие ко многим» (количество, «главная»): промежуточной таблице нужен свой `id` и модель, а родителю — `HasMany` на неё ([рецепт](docs/fields/has-many.md#выбор-записи-в-блоке)). Варианты в блоке всегда ищутся по серверу, подписи выбранных записей всех блоков загружаются одним запросом; запись, вышедшая из вариантов, остаётся выбранной. Адрес поиска блока — `fastleo.resources.options` с именем `блок.поле`. `fastleo:doctor` не предупреждает о поиске по серверу для таких полей.

- **Поле `MorphTo`:** запись одного из нескольких разделов (заметка на статью или товар) двумя списками — раздел и запись с поиском по серверу ([поле](docs/fields/morph-to.md)). Типы — только разделы из `types()`, у каждого можно сузить выбор; произвольный класс из запроса не принимается. Тип записывается как `getMorphClass()` (учитывает `Relation::morphMap()`); связь через Eloquent не читается, поэтому запись с неизвестным типом показывается текстом и не ломает список. Выбрать можно только запись раздела, который администратору разрешено открывать (`viewAny`); сохранённая пара остаётся, пока не изменились и тип, и ключ. Импорт и экспорт — `articles:5`, MCP — `{type, id}`, `fastleo:inspect` показывает `types`, `fastleo:doctor` проверяет колонки, `$fillable`, `ownerKey`, карту типов и ключи разных видов. Подписи записей страницы списка и виджета `Table` грузятся одной выборкой на раздел (новый метод `Field::prepareFor()`).

- **Команда `fastleo:drop-activity`:** удаляет таблицу `fastleo_activity` старого журнала и запись о её миграции (спросит подтверждение, `--force` — без вопроса).
- **`BelongsTo` в блоке:** повтор одного значения в блоках отклоняет правило `->rules(['distinct'])`; поле блока с именем внешнего ключа связи (`product_id` у `bundleItems`) — ошибка описания; значения всех блоков проверяются одним запросом.
- **`MorphTo`:** значение записи с неизвестным типом или закрытым разделом MCP отдаёт как `{type: null, id, morph_class}` и принимает обратно без изменений; сохранённая пара без правки колонки не переписывается.

### Удалено

- **Журнал изменений** (кто, когда, «было → стало», откат, панель истории, пункт меню «Журнал»). Запись по-прежнему идёт через Eloquent: нужен журнал — подключите пакет сайта (например, `spatie/laravel-activitylog`) или свои observers. Из публичного API убрано: `$activity` и `$historyPanel` у ресурса, методы `logsActivity()`, `hasHistoryPanel()`, `showsHistoryPanel()`, `Field::hasHiddenCondition()`, Gate `viewFastleoActivity`, ключ `activity` в `config/fastleo.php`, маршруты `fastleo.activity.*` и `fastleo.resources.history`, классы `Fastleo\Activity\*`, поле `history_panel` в `fastleo:inspect` и MCP. Адрес `activity` снова свободен для своего раздела.
- **После обновления** выполните `php artisan optimize:clear` (устаревший кеш маршрутов ссылается на удалённые класс и контроллер: иначе все страницы админки после входа отвечают 500). Таблицу `fastleo_activity` пакет сам не трогает; когда она не нужна, удалите её командой `php artisan fastleo:drop-activity` (она же убирает запись о миграции); `fastleo:doctor` напомнит, пока таблица или ключ `activity` в `config/fastleo.php` остаются.

### Исправлено

- **Панель массовых действий** в списке больше не заходит под боковое меню (у «Выбрано» обрезалось начало).
- **`KeyValue`:** на широком экране кнопка удаления строки стоит справа, а не слева от ручки; колонки совпадают с заголовками.
- **Видео (`<x-fastleo::video>`):** у iframe нет дубля `allowfullscreen` и `allow`, браузер не пишет предупреждение.
- **Плитка `Stat`:** длинное число (сумма с валютой) уменьшается по длине, а не обрезается троеточием; полное значение — в подсказке.
- **Блоки `HasMany`:** убранные блоки удаляются раньше записи остальных, поэтому с уникальным индексом (родитель + выбранная запись) можно заменить строку; сохранённая запись, вышедшая из вариантов, остаётся только в своём блоке и не выбирается в новом.

## [4.7.4] — 2026-11-04

Вложенные списки, описание картинки и поле видео. Выпуск содержит и новые возможности — по смыслу это минорный выпуск.

### Добавлено

- **`Repeater` и `Blocks` внутри `Repeater` и `Blocks`** (два уровня, не глубже): тарифы с пунктами, этапы работ с шагами, день недели с интервалами приёма. Проверка, ошибки у поля нужного элемента, `required()`, `min()`/`max()`, чистка `RichText`, варианты картинок и `visibleWhen()` (по полю своего элемента) работают на обоих уровнях; перетаскивание и добавление элементов не задевают соседний уровень. Третий уровень даёт понятную ошибку при открытии раздела ([Repeater](docs/fields/repeater.md#список-внутри-элемента), [Blocks](docs/blocks.md)).
- **`Image::alt('cover_alt')`:** описание картинки для сайта в парной колонке — поле ввода под картинкой (доступ у него такой же, как у картинки), внутри `Repeater`/`Blocks` — соседний ключ элемента ([Image](docs/fields/image.md)).
- **Поле `Video`:** ссылка на YouTube, Rutube или VK Видео хранится как вставлена, в форме под полем — плеер; на сайте — компонент `<x-fastleo::video :url="…" />` ([Video](docs/fields/video.md)).
- **Рецепты** в `docs/recipes.md`: координаты, недельное расписание, галерея с подписями.
- **`fastleo:inspect`** показывает подполя `Repeater`, типы и поля `Blocks` и `alt` у картинки; **`fastleo:doctor`** находит ошибки описания внутри `Repeater`/`Blocks` (третий уровень, запрещённое подполе).

### Исправлено

- **MCP `get-record`** отдавал `Blocks` в виде, который `update-record` не принимал: значение теперь берётся в формате ввода, обмен «получил — записал» ничего не меняет.
- **Порядок элементов после записи:** порядок внутренних элементов вложенного списка (в том числе после перетаскивания) сохраняется как в форме.
- **Редактор текста в блоке, перенесённом свёрнутым:** HugeRTE запускается заново, остаток старого экземпляра убирается.

## [4.7.3] — 2026-11-03

Правки по адверсариальному ревью 4.7.0–4.7.2. Главная — адреса ссылок на админку в уведомлениях.

### Исправлено

- **Ссылка на запись в Telegram, Max и письме строилась от хоста запроса или от `APP_URL`:** посетитель сайта мог подменить заголовок `Host` (`X-Forwarded-Host` за доверенным прокси) в `POST /leads` модуля заявок — администраторы получали ссылку на чужой домен, а на сайте с отдельным доменом админки (`fastleo.domain`) письмо и боты вели на домен сайта (404). Теперь полный адрес строит `Fastleo::adminUrl()`: домен админки, если он задан, иначе `APP_URL`; хост запроса не используется нигде. `Fastleo::recordUrl($запись)` тоже даёт такой адрес и годится для письма из очереди.
- **Числовой фильтр:** принимает `.5`, `5.` и `1e3` (поле `type=number` отправляет их как есть), дробная граница уходит в базу строкой — число длиннее 14 значащих цифр больше не округляется.
- **Дерево:** огромный номер страницы в адресе (`?page=9223372036854775807`) даёт пустую страницу вместо ошибки 500.
- **`Image::inTitle()->sortable()`:** сортировки по картинке, у которой нет столбца, нет (`?sort=cover` игнорируется).
- **Окно просмотра** вставляет в окно только карточку своего сайта (`?frame=1`), любой другой адрес открывается обычной страницей.
- **Установщик:** конфликт с ещё не выполненной миграцией сайта, которая создаёт ту же таблицу (`*_create_leads_table.php`), находится до записи файлов; `Dashboard.php` с переводами строк Windows (CRLF) правится, а не отдаётся «вручную»; без терминала (Windows) вопросы `fastleo:user` в первом запуске не задаются — установщик подсказывает команду.
- **Заготовки модулей:** телефон заявки в админке до 50 знаков (как колонка и форма сайта); новости в админке сортируются по дате создания (у новости без даты публикации порядок зависел от базы); ссылка блока «Призыв» принимает только `/путь` или `http(s)://…`.
- **Документация:** опрос и флаги установки (`installation.md`), `README`, ссылки на запись для письма и ботов, кнопки в окне просмотра, оговорка про полностраничный кэш и общий лимит заявок (`modules.md`).

## [4.7.2] — 2026-11-03

Правки по ревью 4.7.1. Если ваш код вызывает `Resource::recordUrl()`, замените на `openUrl()`.

### Исправлено

- **Окно записи:** Esc закрывает окно, когда фокус в поле со списком (`BelongsTo`, `combobox`, фильтр по связи): список гасит Esc, только пока открыт; Esc в окне не закрывает его, если попап внутри формы уже обработал нажатие; «Загрузка…» озвучивается; ссылка на запись с чужим адресом открывается обычной страницей.
- **Вкладки из одних эмодзи** (без букв и цифр в названии) получают ключ `tab-2` по номеру вместо ошибки 500.
- **Документация:** пример администратора в тестах (`tap()` с функцией), ссылка на запись в письме (`Fastleo::mailUrl()`), ссылки в уведомлениях без хоста запроса (`Fastleo::recordUrl($запись, false)`, в том числе в модуле заявок).

### Изменено

- **`Resource::recordUrl()` переименован в `Resource::openUrl()`:** адрес из списков и поиска с проверкой прав; `Fastleo::recordUrl()` (без проверки прав) остался под прежним именем, чтобы два метода не путали.

## [4.7.1] — 2026-11-03

Фильтр по числам, страницы дерева по записям верхнего уровня и настройка столбцов списка. Выпуск содержит и новые возможности (вкладки с таблицами связанных записей, окно записи, ручной порядок в таблице) и меняет умолчание `fastleo.record_view` на `'modal'` — по смыслу это минорный выпуск.

### Добавлено

- **`NumberRangeFilter`:** фильтр списка «от … до …» для чисел (цена, год, наработка); границы целые или десятичные (точка или запятая), любую можно не указывать; у целой колонки дробная граница округляется внутрь диапазона, а граница шире типа колонки сжимается до него (PostgreSQL иначе отвечал ошибкой) ([фильтры](docs/list.md#фильтры)).
- **Выбор столбцов в списке:** кнопка «Столбцы» над списком, выбор помнит браузер администратора ([список](docs/list.md#выбор-столбцов)).
- **`hideWhenEmpty()`:** столбец исчезает из списка, пока на странице у всех записей значение пустое ([список](docs/list.md#какие-поля-видны)).
- **`Image::inTitle()`:** обложка миниатюрой перед заголовком в первой ячейке вместо отдельного столбца ([image](docs/fields/image.md)).
- **Таблица связанных записей во вкладке формы:** `Tab::make('Отзывы', [Related::make('reviews', ReviewResource::class)])` в `fields()`. Вкладка — либо поля, либо таблицы; таблица вне формы и не сохраняется с ней, вкладка запоминается в адресе (`#otzyvy`) ([связанные таблицы](docs/related.md#таблица-во-вкладке-формы)).
- **`Related::editIn('modal'|'page')`:** «Изменить» и «Добавить» из таблицы открывают форму раздела в окне (после сохранения окно закрывается, таблица обновляется) или страницей раздела с возвратом, как раньше ([правка из таблицы](docs/related.md#правка-записи-из-таблицы-страница-или-окно)).
- **`fastleo.record_view`:** по умолчанию (`'modal'`) кнопка «глаз» в списках и таблицах, ссылка `BelongsTo` и строка виджета «Таблица» открывают карточку записи в окне поверх страницы без перехода (без меню и кнопок, правки в окне нет; первый столбец списка ведёт на страницу); `'page'` — отдельная страница, `false` — страницу просмотра можно выключить: адрес отвечает 404, ссылки ведут на форму правки или остаются текстом ([настройки](docs/configuration.md#страница-просмотра-записи)); `Resource::recordUrl()`, `Resource::viewUrl()` и `Fastleo::recordUrl($запись)` — ссылка на запись, подстраивающаяся под настройку; `fastleo:doctor` сообщает об ошибке (`record_view_unknown`), если значение настройки не `'modal'`, `'page'` или `false`.
- **`BelongsTo` в списке ссылкой** на связанную запись, если администратору разрешён её просмотр (`Fastleo::resources()->forModel()`): по настройке `fastleo.record_view` — в окне или на странице.
- **Ручной порядок в связанной таблице:** у дочернего раздела с `$sortColumn` записи таблицы `Related` перетаскиваются ручкой; порядок меняется среди записей одного родителя ([связанные таблицы](docs/related.md#ручной-порядок)).
- **`Table::query(Closure)`:** виджет дашборда «Таблица» сужает записи условием (очередь модерации, заявки без ответа) ([дашборд](docs/dashboard.md#table--последние-записи)).
- **Gate `manageFastleoSoftNetica`:** страницу SoftNetica можно закрыть по ролям, как логи, файлы и кеш ([права](docs/authorization.md#сайт-с-ролями-что-закрыть)).
- **`fastleo:make-resource --generate`:** колонка с enum-кастом становится `Enum::make(...)->enum(...)`, а не `Text`.
- **Документация:** чек-лист «Сайт с ролями», проверка по значениям других полей (`DataAwareRule`), рецепт «Позиции заказа», каст `date:Y-m-d`, список внутри блока, что не переводится, «Подогнать модуль под сайт», сидер администратора, `APP_URL`, `retry_after`, составной ключ импорта.

### Исправлено

- **Ссылка на запись в уведомлениях, вебхуках и очереди** строится без проверки прав текущего администратора (`Resource::recordAddress()`): прежде при Policy ссылка терялась там, где администратора нет.
- **Окно записи:** после сохранения отвечает страница «сохранено» сразу, без перехода: запись, вышедшая из выборки раздела, не даёт 404, а признак не теряется; Esc и крестик с несохранёнными изменениями спрашивают подтверждение; Esc при открытом окне выбора файла закрывает только его; адрес чужого сайта в окно не открывается.
- **Строка виджета «Таблица»** с Ctrl/Cmd/Shift открывается как обычная ссылка; Policy `view` для адреса и окна вызывается один раз на строку (`Resource::viewModalUrl($адрес)`).
- **Ошибки описания вкладок:** `Related` вне вкладки (в `fields()`, секции), `Related` вне формы раздела (настройки, мини-форма действия, блоки `HasMany`) и две вкладки с одним ключом адреса (`SEO` и `Seo`) дают понятное исключение.

- **Свои страницы со своим шаблоном** снова получают пустой `data()` по умолчанию; переменные отчёта идут только странице-отчёту.

## [4.0.0] — 2026-10-30

Пакет написан заново. Совместимости с 2.x и 3.0 нет: как перейти — [docs/upgrade-from-3.md](docs/upgrade-from-3.md).

Composer-имя — `camanru/fastleo`, namespace — `Fastleo\`.

### Требования

- PHP 8.4+, Laravel 13.
- Сайту не нужен npm: CSS и JS админки собраны в пакете.
- Очередь не обязательна: без неё задачи (WebP-варианты, импорт, уведомления) выполняются во время запроса.

### Разделы

- Раздел админки — один класс-ресурс `app/Fastleo/*Resource.php`; разделы находятся сами, список кешируется командой `fastleo:cache` (входит в `optimize`).
- В форме и при записи участвуют только поля из `fields()`; запись — через Eloquent в транзакции (касты, мутаторы, observers, `SoftDeletes`).
- Список: поиск, сортировка, постраничный вывод и «все», мобильные карточки, фильтры (Select, BelongsTo, BelongsToMany, Boolean, DateRange, свои).

- Корзина для `SoftDeletes`, ручной порядок и дерево с перетаскиванием, раздел только для просмотра, «открыть на сайте».
- Действия над записью и массовые с мини-формой (`Fastleo\Actions`).
- Экспорт xlsx/csv потоком, импорт с отчётом об ошибках и файлом пропущенных строк для повторной загрузки (OpenSpout).
