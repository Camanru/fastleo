# Закрытие сайта

Временно закрывает сайт для посетителей — на время обновления, переезда, доработок: вместо страниц сайта посетители видят «Сайт временно не работает» с кодом 503. Админка и вошедшие администраторы работают как обычно и видят сайт, как всегда.

## Включить

В `config/fastleo.php`:

```php
'closing' => [
    'enabled' => true,
],
```

Функция выключена по умолчанию: пока `enabled` равно `false`, страницы в меню нет и на запросах ничего не проверяется. Проверка подключается при старте приложения: после включения пересоберите кеш конфига (`config:cache`), а на Octane перезапустите воркеры.

В админке появится страница «Закрытие сайта» (группа «Настройки», `/fastleo/settings/closing`):

- **Закрыть сайт для посетителей** — галочка;
- **Текст для посетителей** — до 500 символов; пустой — стандартный «Сайт временно не работает. Загляните позже.»

Пока сайт закрыт, вверху каждой страницы админки виден жёлтый баннер «Сайт закрыт для посетителей» со ссылкой на настройку: закрытый сайт не забудут.

## Что видят посетители

- Страница с текстом, код ответа **503** и заголовок `Retry-After: 3600` — поисковики понимают, что закрытие временное, и не выкидывают страницы из выдачи. В страницу добавлен `noindex`.
- Запросам JSON (заголовок `Accept: application/json`) и всем маршрутам группы `api` (даже без этого заголовка) отвечает JSON `{"message": "…"}` с тем же кодом 503.
- Текст по умолчанию и заголовок страницы — на русском, как все тексты пакета, какой бы язык ни был у сайта. Свой текст посетителям задаётся на странице настроек, а страницу при необходимости можно заменить своей (следующий пункт).
- Свой вид страницы: положите файл `resources/views/vendor/fastleo/site-closed.blade.php` — в шаблон приходит переменная `$message`.

## Что остаётся доступным

- **Админка** — все её маршруты (`fastleo.*`), включая вход.
- **Вошедшие администраторы** — те, кому разрешает вход `canAccessFastleo()`. Только для них, и только пока сайт закрыт, в шаблоны сайта приходит переменная `$fastleoSiteClosed` (`true`). В остальных случаях (сайт открыт, функция выключена, зашёл посетитель) её нет, поэтому всегда пишите `?? false`:

  ```blade
  @if ($fastleoSiteClosed ?? false)
      <div class="notice">Посетителям сайт сейчас недоступен</div>
  @endif
  ```
- **Маршруты вне групп `web` и `api`** (например, `robots.txt` и `sitemap.xml` пакета, свои маршруты без групп) закрытием не затрагиваются.

## Ограничения

- Администратор виден на сайте, только если сессия админки доступна сайту. Если админка вынесена на отдельный домен (`fastleo.domain`) и cookie сессии не общие, на основном домене администратор увидит такую же страницу, как посетители. Откройте сайт обратно в админке или пользуйтесь общим доменом cookie (`SESSION_DOMAIN`).
- Закрытие не останавливает очередь, расписание и консольные команды — они работают, как раньше.
- Если настройки прочитать нельзя (например, таблица `fastleo_settings` ещё не создана), сайт остаётся открытым: ошибка чтения не должна ронять весь сайт. Причина записывается в журнал ошибок.
- Адрес страницы настроек `closing` занят встроенной страницей, пока включён `closing.enabled`: своя страница настроек с таким адресом вызовет ошибку в админке (но не закроет и не уронит сайт).
