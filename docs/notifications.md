# Уведомления: колокольчик, Telegram и Max

Колокольчик в шапке админки показывает уведомления администратору: новая заявка, импорт завершён, что-то сломалось. Дополнительно сообщение уходит в чаты администраторов через ботов Telegram и Max (раздел «Уведомления»).

## Отправить уведомление

```php
use Fastleo\Fastleo;
use Fastleo\Notifications\FastleoMessage;

Fastleo::notifyAdmins('Новая заявка');

Fastleo::notifyAdmins(
    FastleoMessage::make('Новая заявка')
        ->body('Иван, +7 900 000-00-00')
        ->url(route('fastleo.resources.show', ['leads', $lead->id], false))
        ->icon('inbox')
        ->level('success'),
);
```

`notifyAdmins()` кладёт уведомление в колокольчик **каждому администратору** и отправляет его один раз в каждый чат включённых ботов раздела «Уведомления». Обычно её вызывают из observer модели или контроллера формы на сайте.

| Метод `FastleoMessage` | Что задаёт |
|---|---|
| `make($title)` | Заголовок, до 150 символов (лишнее обрезается с «…») |
| `body($text)` | Текст, до 500 символов |
| `url($url)` | Ссылка по клику: только `http://`, `https://` или адрес с `/` (но не `//`). Остальное (`javascript:` и т. п.) отбрасывается |
| `icon($name)` | Иконка Lucide, по умолчанию `bell` |
| `level($level)` | `info` (по умолчанию), `success`, `warning`, `danger` — цвет значка |

Одному администратору (только колокольчик): `Fastleo::notify($user, 'Готов отчёт')`.

## Копия на почту

Чтобы уведомление приходило и письмом, включите в `config/fastleo.php`:

```php
'notifications' => [
    'mail' => true,
],
```

`notifyAdmins()` отправит каждому администратору, у которого есть адрес почты, письмо: заголовок — тема, текст — абзац, ссылка — кнопка «Открыть» (относительная ссылка строится от `APP_URL`). Уровень `success` даёт зелёную кнопку, `danger` — красную. Письма идут через очередь сайта; без очереди (`sync`) отправляются сразу, поэтому на сайте с заметным числом администраторов очередь лучше включить. Почта должна быть настроена на сайте (`MAIL_*`); сбой отправки не мешает колокольчику, ботам и коду сайта, который вызвал `notifyAdmins()`. `Fastleo::notify($user, …)` на почту не отправляет.

## Кто получает уведомления

Пользователи с `fastleo_admin = true`, которым `canAccessFastleo()` разрешает вход. Если на сайте доступ определяется иначе (например, `canAccessFastleo()` проверяет роль, а колонку `fastleo_admin` вы не ведёте), задайте получателей сами в `AppServiceProvider::boot()`:

```php
Fastleo::resolveAdminsUsing(fn () => User::role('editor')->get());
```

`resolveAdminsUsing(null)` возвращает выбор по умолчанию.

## Свой класс уведомления

Колокольчик — обычный канал Laravel Notifications с именем `fastleo`. Свои уведомления сайта могут писать в него же:

```php
use Fastleo\Notifications\FastleoMessage;
use Illuminate\Notifications\Notification;

final class LeadCreated extends Notification
{
    public function __construct(private readonly Lead $lead) {}

    public function via(object $notifiable): array
    {
        return ['fastleo', 'mail'];
    }

    public function toFastleo(object $notifiable): FastleoMessage
    {
        return FastleoMessage::make('Новая заявка')->body($this->lead->name);
    }
}

Notification::send(Fastleo::admins(), new LeadCreated($lead));
```

Метод `toFastleo()` обязателен: уведомление без него канал пропускает.

## Колокольчик

Число непрочитанных обновляется каждую минуту и при открытии списка. В списке — 20 последних; клик по уведомлению отмечает его прочитанным и открывает ссылку; «Прочитать все» отмечает всё разом. Читать и отмечать можно только свои уведомления.

Пакет сам пишет в колокольчик автору импорта: «Импорт завершён» со ссылкой на отчёт или «Импорт не выполнен» ([экспорт и импорт](import-export.md)).

## Боты Telegram и Max

Раздел **Система → Уведомления** — список ботов. У каждого: название, мессенджер, токен, чаты получателей и галочка «Отправлять уведомления». Это служебные чаты администраторов (личные или рабочая группа), а не каналы для подписчиков — для них есть [публикации](publishing.md).

1. Создайте бота: в Telegram — у [@BotFather](https://t.me/BotFather), в Max — в разделе «Чат-боты» кабинета Max для партнёров. Скопируйте токен.
2. Напишите боту любое сообщение или добавьте его в рабочую группу.
3. В админке откройте **Уведомления → Создать**, выберите мессенджер, вставьте токен и нажмите **«Найти чаты бота»** — появятся чаты, где бот недавно был; добавьте нужные. Номер можно вписать и вручную: в Telegram — число или `@имя` канала, в Max — только число.
4. Сохраните и нажмите действие **«Отправить тест»** — сообщение уйдёт сразу, минуя очередь.

«Найти чаты бота» читает последние события бота (`getUpdates` в Telegram, `GET /updates` в Max). Если у бота уже настроен webhook (бот работает в другой программе), мессенджер их не отдаёт — впишите номер вручную.

Токен хранится зашифрованным (ключ приложения), в форме, на просмотре, в журнале изменений и через MCP не показывается: пустое поле при сохранении оставляет прежний токен, новый — заменяет. Каждый чат — отдельная задача `SendAdminMessage`: в фоне, если на сайте настроена очередь, иначе сразу; 3 попытки с паузой 10 и 60 секунд, а если мессенджер просит подождать — ждёт. Повтор не дублирует сообщение в чатах, куда оно уже ушло; если связь оборвалась после отправки (сообщение могло дойти), задача не повторяется. Сбой мессенджера не ломает ни сайт, ни админку (при очереди `sync` он записывается в журнал ошибок сайта), а токен не попадает ни в ошибки, ни в лог. Если сменить мессенджер у готового бота, нужно ввести токен заново: токен Telegram не подходит Max и наоборот.

**Адрес раздела.** Раздел «Уведомления» открывается по адресу `notification-bots`. Если у сайта уже есть свой раздел с таким адресом, встроенный не появится (молча, без ошибки): задайте своему разделу другой `$slug` или отключите встроенный (`'notifications' => ['bots' => null]`). `php artisan fastleo:doctor` предупреждает об этом.

**Max и сертификат Минцифры.** API Max (`platform-api2.max.ru`) подписан корневым сертификатом Минцифры (Russian Trusted Root CA), которого нет в обычных хранилищах сертификатов. Пакет доверяет ему **только в запросах к API Max** — сертификат лежит в пакете, системные настройки сервера не меняются. Свой файл — `'messengers' => ['max' => ['certificate' => '/путь/к/сертификату.pem']]`.

Раздел убирается целиком: `'notifications' => ['bots' => null]`. Свой вариант раздела — наследник `Fastleo\Notifications\NotificationBotResource` в этом же ключе.

## Настройки

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `notifications.keep_days` | `90` | Сколько дней хранятся уведомления; чистит `fastleo:prune` |
| `notifications.mail` | `false` | Дублировать `notifyAdmins()` письмом каждому администратору с адресом ([подробнее](#копия-на-почту)) |
| `notifications.bots` | `NotificationBotResource::class` | Раздел «Уведомления» (боты Telegram и Max); `null` — раздела и отправки в мессенджеры нет |
| `messengers.max.url` | `https://platform-api2.max.ru` | Адрес Bot API Max |
| `messengers.max.certificate` | `null` | Сертификат для запросов к API Max; `null` — сертификат Минцифры из пакета |

Подробнее — [настройки `config/fastleo.php`](configuration.md).
