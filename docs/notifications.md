# Уведомления: колокольчик, Telegram и Max

Колокольчик в шапке админки показывает уведомления администратору: новая заявка, импорт завершён, что-то сломалось. Дополнительно сообщение уходит в чаты администраторов через ботов Telegram и Max (раздел «Боты уведомлений») и на почту. Все три канала по умолчанию выключены: сайт включает только то, что ему нужно.

## Как включить колокольчик

В `config/fastleo.php`:

```php
'notifications' => [
    'bell' => true,
    'poll' => 60, // как часто обновлять число непрочитанных, секунд
],
```

Таблица `fastleo_notifications` уже есть после `php artisan migrate`. Если конфиг закеширован, выполните `php artisan optimize`.

Варианты `poll`:

| Значение | Что происходит |
|---|---|
| `60` (по умолчанию) | Число непрочитанных обновляется раз в минуту, пока вкладка открыта и видна |
| `300` | Раз в 5 минут: меньше запросов к серверу, если уведомления редкие |
| больше `86400` | Раз в сутки — реже колокольчик не опрашивает |
| от `1` до `10` | Раз в 10 секунд — чаще колокольчик не опрашивает (дробная часть отбрасывается: `0.5` — без опроса) |
| `null` (или `0`) | Без опроса: число обновляется при загрузке страницы и при открытии колокольчика |

Пока колокольчик выключен (`'bell' => false`, по умолчанию), его нет в шапке, адреса колокольчика отвечают 404, а уведомления в колокольчик (`Fastleo::notify()`, итог импорта, сбой публикации, свои классы с каналом `fastleo`) не сохраняются. `notifyAdmins()` при этом продолжает слать письма и сообщения ботам, если они включены.

## Отправить уведомление

```php
use Fastleo\Fastleo;
use Fastleo\Notifications\FastleoMessage;

Fastleo::notifyAdmins('Новая заявка');

Fastleo::notifyAdmins(
    FastleoMessage::make('Новая заявка')
        ->body('Иван, +7 900 000-00-00')
        ->url(Fastleo::recordUrl($lead, false))
        ->icon('inbox')
        ->level('success'),
);
```

`notifyAdmins()` отправляет уведомление во все включённые каналы: в колокольчик **каждому администратору**, письмом каждому администратору с адресом и один раз в каждый чат включённых ботов раздела «Боты уведомлений» (только в часть каналов — [via](#куда-отправлять)). Обычно её вызывают из observer модели или контроллера формы на сайте. Если боты включены, но прочитать их не удалось (не выполнена миграция, база недоступна), мессенджеры пропускаются, а причина попадает в журнал ошибок: страница сайта с формой заявки не отвечает ошибкой 500.

| Метод `FastleoMessage` | Что задаёт |
|---|---|
| `make($title)` | Заголовок, до 150 символов (лишнее обрезается с «…») |
| `body($text)` | Текст, до 500 символов |
| `url($url)` | Ссылка по клику: только `http://`, `https://` или адрес с `/` (но не `//`). Остальное (`javascript:` и т. п.) отбрасывается |
| `icon($name)` | Иконка Lucide, по умолчанию `bell` |
| `level($level)` | `info` (по умолчанию), `success`, `warning`, `danger` — цвет значка |

Одному администратору (только колокольчик): `Fastleo::notify($user, 'Готов отчёт')`.

## Куда отправлять

По умолчанию `notifyAdmins()` шлёт во все включённые каналы. Чтобы отправить только в некоторые, перечислите их в `via`:

```php
// срочное — только в чаты ботов
Fastleo::notifyAdmins(FastleoMessage::make('Оплата не прошла')->level('danger'), via: ['bots']);

// в колокольчик и на почту, без мессенджеров
Fastleo::notifyAdmins('Новый отзыв на модерации', via: ['bell', 'mail']);
```

| Канал | Куда | Включается |
|---|---|---|
| `bell` | Колокольчик в шапке | `notifications.bell` ([как](#как-включить-колокольчик)) |
| `mail` | Письмо каждому администратору с адресом | `notifications.mail` ([как](#копия-на-почту)) |
| `bots` | Чаты ботов Telegram и Max | `notifications.bots` ([как](#как-включить-ботов)) |

Канал из `via`, выключенный в конфиге, пропускается без ошибки: один и тот же код работает на сайтах с разным набором каналов. Неизвестное имя (например, `'telegram'`) или пустой список `via: []` — исключение `InvalidArgumentException` со списком допустимых, чтобы опечатка не теряла уведомления молча. Во все включённые каналы — вызов без `via`.

## Копия на почту

Чтобы уведомление приходило и письмом, включите в `config/fastleo.php`:

```php
'notifications' => [
    'mail' => true,
],
```

`notifyAdmins()` отправит каждому администратору, у которого есть адрес почты, письмо: заголовок — тема, текст — абзац, ссылка — кнопка «Открыть» (относительная ссылка достраивается до полного адреса одинаково в письме и в сообщениях ботов: на домене админки `fastleo.domain`, если он задан, иначе от `APP_URL`; хост запроса посетителя не используется). Уровень `success` даёт зелёную кнопку, `danger` — красную. Письма идут через очередь сайта; без очереди (`sync`) отправляются сразу, поэтому на сайте с заметным числом администраторов очередь лучше включить. Почта должна быть настроена на сайте (`MAIL_*`); сбой отправки не мешает колокольчику, ботам и коду сайта, который вызвал `notifyAdmins()`. `Fastleo::notify($user, …)` на почту не отправляет.

## Кто получает уведомления

Пользователи с `fastleo_admin = true`, которым `canAccessFastleo()` разрешает вход. Если на сайте доступ определяется иначе (например, `canAccessFastleo()` проверяет роль, а колонку `fastleo_admin` вы не ведёте), задайте получателей сами в `AppServiceProvider::boot()`:

```php
Fastleo::resolveAdminsUsing(fn () => User::role('editor')->get());
```

`resolveAdminsUsing(null)` возвращает выбор по умолчанию.

### Колокольчик только некоторым

Колокольчик в конфиге включается для всей админки. Если он нужен не всем (в CRM — владельцу, а менеджерам нет), скажите, кому его показывать, в `AppServiceProvider::boot()`:

```php
Fastleo::showBellTo(fn (User $user) => $user->is_owner === true);   // только строгий true показывает колокольчик
```

У остальных администраторов нет колокольчика и пункта «Уведомления» в меню, их адреса отвечают 404, а уведомления им не сохраняются (почта и боты работают как настроено). `showBellTo(null)` возвращает показ всем. Конфиг остаётся главным выключателем: при `bell => false` колокольчика нет ни у кого.

## Свой класс уведомления

Колокольчик — обычный канал Laravel Notifications с именем `fastleo`. Свои уведомления сайта могут писать в него же (колокольчик должен быть [включён](#как-включить-колокольчик), иначе канал ничего не сохраняет):

```bash
php artisan make:notification LeadCreated         # app/Notifications/LeadCreated.php
```

```php
// app/Notifications/LeadCreated.php
namespace App\Notifications;

use App\Models\Lead;
use Fastleo\Notifications\FastleoMessage;
use Illuminate\Notifications\Notification;

final class LeadCreated extends Notification
{
    public function __construct(private readonly Lead $lead) {}

    public function via(object $notifiable): array
    {
        return ['fastleo'];
    }

    public function toFastleo(object $notifiable): FastleoMessage
    {
        return FastleoMessage::make('Новая заявка')->body($this->lead->name);
    }
}

// где отправляете (observer, контроллер)
Notification::send(Fastleo::admins(), new LeadCreated($lead));
```

Метод `toFastleo()` обязателен: уведомление без него канал пропускает.

## Колокольчик

Число непрочитанных обновляется с частотой `notifications.poll` (по умолчанию раз в минуту) и при открытии списка. В списке — 20 последних; клик по уведомлению отмечает его прочитанным и открывает ссылку; «Прочитать все» отмечает всё разом. Читать и отмечать можно только свои уведомления.

**Все уведомления** — раздел **Система → Уведомления** (`/fastleo/notifications`, ссылка «Все уведомления» внизу колокольчика). В нём свои уведомления за весь срок хранения (`notifications.keep_days`, по умолчанию 90 дней), новые сверху, по 30 на странице, в том числе уже прочитанные; переключатель «Все / Непрочитанные», кнопки «Открыть» (отмечает прочитанным и переходит по ссылке), «Прочитано» и «Прочитать все». Пункт меню есть, только пока колокольчик включён; при выключенном адрес раздела отвечает 404, как и остальные адреса колокольчика.

Пакет сам пишет в колокольчик автору импорта: «Импорт завершён» со ссылкой на отчёт или «Импорт не выполнен» ([экспорт и импорт](import-export.md)), и автору публикации, если она не дошла ([публикации](publishing.md)). При выключенном колокольчике эти уведомления не создаются: итог импорта виден в отчёте импорта, итог публикации — в её журнале отправки. `php artisan fastleo:doctor` предупреждает об этом, если на сайте есть импорт или публикации.

## Боты Telegram и Max

Раздел **Мессенджеры → Боты уведомлений** — список ботов (по умолчанию выключен, как включить — [ниже](#как-включить-ботов)). У каждого: название, мессенджер, токен, чаты получателей и галочка «Отправлять уведомления». Это служебные чаты администраторов (личные или рабочая группа), а не каналы для подписчиков — для них есть [публикации](publishing.md).

1. Создайте бота: в Telegram — у [@BotFather](https://t.me/BotFather), в Max — в разделе «Чат-боты» кабинета Max для партнёров. Скопируйте токен.
2. Напишите боту любое сообщение или добавьте его в рабочую группу.
3. В админке откройте **Боты уведомлений → Создать**, выберите мессенджер, вставьте токен и нажмите **«Найти чаты бота»** — появятся чаты, где бот недавно был; добавьте нужные. Номер можно вписать и вручную: в Telegram — число или `@имя` канала, в Max — только число.
4. Сохраните и нажмите действие **«Отправить тест»** — сообщение уйдёт сразу, минуя очередь.

«Найти чаты бота» читает последние события бота (`getUpdates` в Telegram, `GET /updates` в Max). Если у бота уже настроен webhook (бот работает в другой программе), мессенджер их не отдаёт — впишите номер вручную. Набор событий бота пакет не меняет, поэтому сайт, который сам читает того же бота, продолжает получать свои события. Но если боту раньше вручную ограничили набор событий (`allowed_updates`) и в нём нет `message`, `channel_post` и `my_chat_member`, мессенджер этих чатов тоже не отдаёт — впишите номер вручную.

Токен хранится зашифрованным, сообщения уходят в фоне (если на сайте есть очередь), а сбой мессенджера не ломает ни сайт, ни админку.

**Как идёт отправка:**

- **Токен** зашифрован ключом приложения и нигде не показывается: ни в форме, ни на просмотре, ни через MCP. Пустое поле при сохранении оставляет прежний токен, новый — заменяет. Если сменить мессенджер у готового бота, введите токен заново: токен Telegram не подходит Max и наоборот.
- **Каждый чат — отдельная задача** `SendAdminMessage`: в фоне, если на сайте настроена очередь, иначе сразу.
- **Повторы:** 3 попытки с паузой 10 и 60 секунд; если мессенджер просит подождать — ждёт. Повтор не дублирует сообщение в чатах, куда оно уже ушло. Если связь оборвалась после отправки (сообщение могло дойти), задача не повторяется.
- **Сбой** мессенджера при очереди `sync` записывается в журнал ошибок сайта. Токен не попадает ни в ошибки, ни в лог.

**Адрес раздела.** Раздел «Боты уведомлений» открывается по адресу `notification-bots`. Если у сайта уже есть свой раздел с таким адресом, встроенный не появится (молча, без ошибки): задайте своему разделу другой `$slug` или отключите встроенный (`'notifications' => ['bots' => null]`). `php artisan fastleo:doctor` предупреждает об этом.

**Max и сертификат Минцифры.** API Max (`platform-api2.max.ru`) подписан корневым сертификатом Минцифры (Russian Trusted Root CA), которого нет в обычных хранилищах сертификатов. Пакет доверяет ему **только в запросах к API Max** — сертификат лежит в пакете, системные настройки сервера не меняются. Свой файл — `'messengers' => ['max' => ['certificate' => '/путь/к/сертификату.pem']]`.

### Как включить ботов

По умолчанию раздела «Боты уведомлений» нет, и `notifyAdmins()` пишет только в колокольчик и на почту (если они [включены](#как-включить-колокольчик)). Включается в `config/fastleo.php`:

```php
'notifications' => [
    'bots' => Fastleo\Notifications\NotificationBotResource::class,
],
```

После этого в меню появляется **Мессенджеры → Боты уведомлений**, а `notifyAdmins()` отправляет уведомления во все включённые боты (кроме вызовов с `via` без `bots`). Таблица `fastleo_notification_bots` уже есть после `php artisan migrate`. Если конфиг закеширован, выполните `php artisan optimize`.

**Свой вариант раздела** (другая группа меню, подпись, права) — наследник в папке разделов сайта, и его класс в том же ключе:

```php
// app/Fastleo/BotResource.php
namespace App\Fastleo;

use Fastleo\Notifications\NotificationBotResource;

final class BotResource extends NotificationBotResource
{
    protected static ?string $group = 'Настройки';

    protected static ?string $label = 'Боты для админов';
}
```

```php
// config/fastleo.php
'notifications' => [
    'bots' => App\Fastleo\BotResource::class,
],
```

Класс нужно указать в ключе, даже если он лежит в `app/Fastleo`: без ключа раздел будет виден, но `notifyAdmins()` не станет слать сообщения в мессенджеры.

Выключить снова — `'bots' => null`: раздел пропадёт, а `notifyAdmins()` перестанет писать в мессенджеры; сохранённые боты останутся в таблице. Свой класс-наследник из папки разделов сайта (`app/Fastleo`) раздел находит и без ключа — чтобы убрать его из меню, удалите класс или вынесите из этой папки.

## Настройки

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `notifications.bell` | `false` | Колокольчик в шапке ([как включить](#как-включить-колокольчик)) |
| `notifications.poll` | `60` | Как часто колокольчик обновляет число непрочитанных, секунд (от 10 секунд до суток); `null` — без опроса |
| `notifications.keep_days` | `90` | Сколько дней хранятся уведомления; чистит `fastleo:prune` |
| `notifications.mail` | `false` | Отправлять уведомления `notifyAdmins()` письмом каждому администратору с адресом ([подробнее](#копия-на-почту)) |
| `notifications.bots` | `null` | Раздел «Боты уведомлений» (боты Telegram и Max); `null` — раздела и отправки в мессенджеры нет, включить — `NotificationBotResource::class` или свой наследник ([как](#как-включить-ботов)) |
| `messengers.max.url` | `https://platform-api2.max.ru` | Адрес Bot API Max |
| `messengers.max.certificate` | `null` | Сертификат для запросов к API Max; `null` — сертификат Минцифры из пакета |

Подробнее — [настройки `config/fastleo.php`](configuration.md).
