# Переезд с другой админки

Памятка для сайта, который уже работает с прежней админкой (MoonShine, самописной или другой) и переходит на fastleo. Разделы описываются классами ([resources.md](resources.md)) — на это уходит меньше всего времени. Дольше всего занимают места, где fastleo сталкивается со старыми данными: администраторы, таблица сброса пароля, пути картинок, «пустые» значения в колонках. Они собраны ниже.

С fastleo 2.x и 3.0 — отдельный документ: [upgrade-from-3.md](upgrade-from-3.md).

Перед началом сделайте копию базы и файлов. В конце запустите `php artisan fastleo:doctor` — он проверяет большую часть этого списка и называет, что исправить.

## 1. Администраторы

Вход в fastleo — guard `fastleo` на модели пользователей сайта; право входа даёт колонка `fastleo_admin` (трейт `HasFastleoAccess`, [installation.md](installation.md#2-модель-пользователя)). Флаг в `$fillable` не добавляют никогда.

- **Администраторы в той же таблице, что и посетители** (`users`): выдайте флаг командой `php artisan fastleo:user admin@site.ru`.
- **Администраторы в отдельной таблице.** У MoonShine по умолчанию это `moonshine_users` с собственной моделью. Два пути: перенести администраторов в `users` и выдать флаг командой выше (проще), либо указать модель администраторов провайдером guard — `'auth' => ['provider' => 'admins']` в `config/fastleo.php` и провайдер `admins` в `config/auth.php`; трейт и колонка `fastleo_admin` тогда нужны этой модели ([auth.md](auth.md)).
- Пароли остаются прежними, если хеш в формате Laravel (bcrypt/argon). Адрес входа сравнивается в нижнем регистре. Если прежняя система хранила пароли в своём формате (например, `md5`), их можно принять и заменить на bcrypt при первом входе — [recipes.md](recipes.md#старые-пароли-при-переезде).

## 2. Сброс пароля

«Забыли пароль?» хранит ссылки в таблице `password_reset_tokens`. В проектах на Laravel 5–9 вместо неё лежит `password_resets`, а в самописных иногда нет ни одной. Без таблицы кнопка падает с ошибкой — и только при нажатии. `fastleo:doctor` проверяет таблицу заранее. Что сделать — [auth.md](auth.md#забыли-пароль): переименовать таблицу, создать её или описать брокер `fastleo` на существующую `password_resets` (не переименовывайте её, если ею пользуется сброс пароля самого сайта).

## 3. `migrate` падает: «уже существует»

Если раньше на сайте стояла другая версия fastleo или таблица/колонка с тем же именем, миграция пакета падает с ошибкой «уже существует» — или повторно пытается добавить колонку, потому что в таблице `migrations` нет записи о ней. `fastleo:doctor` показывает такие миграции до запуска `migrate`. Решение — переименовать старую колонку или таблицу миграцией сайта, которая идёт **раньше** миграций пакета: [upgrade-from-3.md](upgrade-from-3.md#5-миграции-и-перенос-администраторов). Если таблица уже создана этой же версией и потерялась только запись, добавьте строку с именем миграции в таблицу `migrations`.

## 4. Картинки и файлы

В колонке fastleo хранит путь относительно диска — `uploads/doctors/ivanov.jpg` ([files.md](files.md)). Старые админки писали иначе:

| В колонке | Что делать |
|---|---|
| `/storage/uploads/a.jpg` | Отрезать `/storage/`: готовая миграция в [upgrade-from-3.md](upgrade-from-3.md#6-файлы) |
| `https://site.ru/storage/uploads/a.jpg` | Отрезать начало до `uploads/`; вручную или своей миграцией |
| `photo.jpg` (имя файла, лежит в `public/uploads`) | Дописать `uploads/` и перенести файлы (ниже) |

Миграция для голых имён. Запускайте её **после** того, как адреса с `/storage/` уже приведены к `uploads/…`: она трогает только значения без `/`, остальные оставляет как есть. Файлы обновляйте через `chunkById`: обычные `chunk()`/`lazy()` со смещением пропускают строки, когда сами меняют значение, по которому отбирают.

```bash
php artisan make:migration prefix_upload_paths
```

```php
use Illuminate\Database\Migrations\Migration;
use Illuminate\Support\Facades\DB;

return new class extends Migration
{
    /**
     * 'photo.jpg' → 'uploads/photo.jpg' в колонках с файлами.
     *
     * @var array<string, list<string>>
     */
    private array $columns = ['products' => ['photo']];

    public function up(): void
    {
        foreach ($this->columns as $table => $columns) {
            foreach ($columns as $column) {
                DB::table($table)
                    ->whereNotNull($column)
                    ->where($column, '!=', '')
                    ->where($column, 'not like', '%/%')
                    ->chunkById(500, function ($rows) use ($table, $column): void {
                        foreach ($rows as $row) {
                            DB::table($table)->where('id', $row->id)->update([$column => 'uploads/'.ltrim($row->{$column}, '/')]);
                        }
                    });
            }
        }
    }
};
```

Файлы переносят в `storage/app/public/uploads` (диск `public`, корень менеджера — `files.root`). Если на сайте остались старые ссылки вида `/uploads/a.jpg` (в текстах, чужих сайтах), оставьте их рабочими ссылкой: `ln -s ../storage/app/public/uploads public/uploads`. Для адресов `/storage/…` нужна обычная ссылка `php artisan storage:link`. После — проверка, что не осталось значений в другом виде: `SELECT id, photo FROM products WHERE photo IS NOT NULL AND photo NOT LIKE 'uploads/%';`.

## 5. «Пустое» значение в колонке

Форма отправляет пустое поле как `null`. Сайты со старой админкой часто хранят «нет значения» иначе, и это ломается молча:

- **Ноль вместо «нет»** (`category_id = 0` — без основной категории). Выбор из списка добавляет пустой вариант «—», и после сохранения в колонке `NULL`; шаблон сайта, который ждёт `0`, ломается. Решение — `emptyValue(0)` у поля, подпись пустого варианта — `placeholder()`:

```php
Select::make('category_id', 'Основная категория')
    ->options(fn () => Category::query()->pluck('title', 'id')->all())
    ->placeholder('Без основной')
    ->emptyValue(0),
```

- **NOT NULL-колонка и пустой текст.** Пустой `RichText`, `Text` или `Textarea` сохраняется как `NULL`, а колонка этого не допускает: запись не сохраняется. Сделайте колонку `nullable` миграцией или задайте полю `emptyValue('')`. `fastleo:doctor` предупреждает о таких колонках.
- **Значение, которого нет среди вариантов** (старый код статуса): форма показывает его отдельным выбранным вариантом и не стирает при сохранении ([select.md](fields/select.md)).

## 6. Заголовок записи

Название записи в заголовке формы, хлебных крошках, дереве и поиске fastleo берёт из **первого столбца списка, который не является связью**. Если первым стоит `Select` или `Image`, в заголовке окажется их значение. Поставьте первым поле с названием или переопределите `title()` ([resources.md](resources.md#title)).

## 7. Выгрузки и очистка

- Старые файлы выгрузок прежней админки (`storage/exports`, `public/exports`) удалите или закройте: пакет файлы выгрузки не сохраняет — они отдаются в браузер сразу, поэтому их нет и на публичном диске. Если на публичном диске остался xlsx с данными, он доступен по прямому адресу.
- Большие таблицы выгружайте в csv ([import-export.md](import-export.md#экспорт)).
- Кеш списка разделов необязателен: после `fastleo:clear` разделы находятся и без него, он только ускоряет работу на боевом сайте ([resources.md](resources.md#кеш-списка-разделов)).

## Чек-лист

1. Администраторы вошли; `fastleo:user` выдал флаг.
2. Нажали «Забыли пароль?» — письмо ушло.
3. `php artisan migrate` проходит на копии базы.
4. Картинки открываются в формах и на сайте; в колонках только `uploads/…`.
5. Сохранили запись с пустым выбором и пустым текстом — ошибок нет, в базе ожидаемые значения.
6. `php artisan fastleo:doctor` — без ошибок.
