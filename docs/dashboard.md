# Дашборд

Главная страница админки — сетка виджетов: числа, графики, последние записи, плитки разделов, состояние сервера. Без настройки показываются **плитки разделов** и **состояние сервера**; свой набор описывается классом.

## Свой дашборд

Создайте класс `Dashboard` рядом с ресурсами (по умолчанию `app/Fastleo/Dashboard.php`, namespace `App\Fastleo`) и верните виджеты:

```php
namespace App\Fastleo;

use App\Models\Lead;
use Fastleo\Widgets\{Chart, Sections, ServerStatus, Stat, Table};

final class Dashboard extends \Fastleo\Dashboard
{
    public function widgets(): array
    {
        return [
            Stat::make('Заявки сегодня')
                ->value(fn () => Lead::whereDate('created_at', today())->count())
                ->description(fn () => 'всего '.Lead::count())
                ->icon('inbox')
                ->url(route('fastleo.resources.index', 'leads')),

            Chart::make('Заявки по дням')->line()->data(fn () => Chart::countByDay(Lead::query()))->columnSpan(2),

            Table::make('Последние заявки')->resource(LeadResource::class)->limit(5)->columnSpan(2),

            Sections::make()->columnSpan(2),
            ServerStatus::make()->columnSpan(4),
        ];
    }
}
```

Класс находится сам (как ресурсы): он должен лежать в папке и namespace из `fastleo.resources.path` / `fastleo.resources.namespace`. Есть свой класс — встроенный набор не показывается, нужные встроенные виджеты (`Sections`, `SoftNetica`, `ServerStatus`) добавьте в список.

## Раскладка

Сетка — четыре колонки (на планшете две, на телефоне одна). У виджета два размера: ширина `->columnSpan(1…4)` в колонках и высота `->rowSpan(1…4)` в строках; по умолчанию 1×1. Высота — «не меньше N строк»: если содержимое выше, строка растёт. Виджеты идут слева направо и сверху вниз в порядке списка, карточка занимает всю свою ячейку, поэтому на широком экране две плитки можно поставить друг под другом рядом с высоким графиком (на планшете, где две колонки, график встаёт строкой ниже):

```php
return [
    Stat::make('Заявки сегодня')->value(fn () => Lead::whereDate('created_at', today())->count()),     // 1×1
    Chart::make('Заявки за 30 дней')->bar()->data(fn () => Chart::countByDay(Lead::query()))->columnSpan(3)->rowSpan(2),
    Stat::make('Не дошли на почту')->value(fn () => Lead::where('mail_sent', false)->count()),         // 1×1 под первой плиткой
    Table::make('Последние заявки')->resource(LeadResource::class)->columnSpan(4),
];
```

Общие методы виджета:

| Метод | Что делает |
|---|---|
| `Виджет::make('Заголовок')` | Создать виджет |
| `->columnSpan(2)` | Ширина в колонках (1–4) |
| `->rowSpan(2)` | Высота в строках (1–4) |
| `->key('leads-today')` | Постоянный ключ для настроек администратора (латиница в нижнем регистре, цифры, дефис, до 100 знаков) |
| `->visible(fn ($user) => $user->is_owner)` | Показывать не всем: замыкание получает администратора. `->visible(false)` — скрыть |

### Настройка в админке

Кнопка «Настроить» над сеткой включает режим правки: у каждой карточки появляются ручка для перетаскивания, кнопки «−/+» для ширины и высоты (1–4) и «Скрыть/Показать». «Сохранить» запоминает раскладку **для этого администратора** (таблица `fastleo_dashboard_layouts`, после обновления пакета выполните `php artisan migrate`), «Отмена» ничего не меняет, «Вернуть как было» удаляет настройки и возвращает раскладку из кода. Скрытый виджет не считает данные.

Правила:
- Настройки хранятся по ключу виджета. Без `->key()` ключ строится из класса и заголовка (`stat-zaiavki-segodnia`; одинаковые получают `-2`, `-3`), поэтому при смене заголовка настройки этого виджета сбрасываются к значениям из кода. Для виджетов, чей заголовок меняется, задайте `->key()`.
- Заданный `key()` не меняется; ключ из заголовка, совпавший с занятым, получает суффикс. Новый виджет, добавленный в код, встаёт после уже настроенных; удалённый из кода пропадает из настроек сам.
- Виджет, закрытый через `visible()` или Policy, администратору не показывается и в его раскладку не сохраняется.

Если при подготовке данных виджет упал (ошибка запроса, недоступный сервис), в его карточке будет «Не удалось загрузить.», остальной дашборд работает, а исключение попадает в лог.

## Stat — число

```php
Stat::make('Выручка')
    ->value(fn () => number_format(Order::sum('total'), 0, ',', ' ').' ₽')   // число, строка или замыкание
    ->description('за всё время')                                              // строка или замыкание
    ->icon('wallet')                                                           // иконка Lucide
    ->url('/fastleo/orders');                                                  // ссылка с плитки: строка или замыкание
```

Числа форматируются с пробелами между тысячами («1 234 567»); строка выводится как есть. Ссылка допускает только `http(s)://` и адреса с `/`. Замыкание выбирает ссылку при показе дашборда: `->url(fn () => Lead::exists() ? route('fastleo.resources.index', 'leads') : route('fastleo.resources.create', 'leads'))`; `null` — без ссылки.

## Chart — график

```php
Chart::make('Заявки за 30 дней')->line()->data(fn () => Chart::countByDay(Lead::query()));
Chart::make('По статусам')->bar()->label('Заявок')->data(fn () => ['Новые' => 4, 'В работе' => 9]);
```

- `->line()` — линия, `->bar()` — столбцы; `->data()` возвращает массив «подпись → число» (до 365 точек).
- `Chart::countByDay($запрос_или_класс_модели, 'created_at', 30)` — сколько записей создавалось в каждый из последних дней (дни без записей — нули). Дни считаются в часовом поясе админки (`fastleo.timezone`, [конфигурация](configuration.md#часовой-пояс)); если он отличается от пояса сайта, база группирует по часам, а в дни их складывает PHP (в поясах со сдвигом в полчаса запись у границы суток может попасть в соседний день). Записи не загружаются; запрос можно сузить: `Lead::query()->where('status', 'new')`.
- Графики рисует Chart.js. Файл `fastleo-chart.js` подключается только на дашборде, где есть график.

## Table — последние записи

```php
Table::make('Последние заявки')->resource(LeadResource::class)->limit(5);
```

Первые четыре столбца списка ресурса, новые записи сверху, название ведёт на страницу записи. Виджет не показывается тому, кому по Policy нельзя открывать раздел (`viewAny`); ссылки на записи — только тем, кому доступен просмотр (`view`). Без заголовка берётся название раздела. Раздел должен быть описан ресурсом сайта.

## Sections — плитки разделов

Те же разделы, что и в меню (с учётом Policy), с иконками и счётчиками `badge()` — удобно для «заявки без ответа: 3».

## ServerStatus — состояние сервера

Версии (Fastleo, Laravel, PHP, база данных), окружение, время и проверки. У каждого замечания есть причина и команда для исправления; в шапке карточки — «Требует внимания: N».

| Проверка | Когда замечание |
|---|---|
| Режим отладки `APP_DEBUG` | включён на боевом сайте (`APP_ENV=production`) — критично |
| Режим обслуживания | сайт закрыт командой `php artisan down` — критично |
| Кеш конфигурации и маршрутов | на боевом сайте не закеширован: `php artisan optimize` |
| Очередь | драйвер `sync`: тяжёлые задачи идут во время запроса; при настоящей очереди — сколько задач ждёт, и предупреждение, если самая старая ждёт больше 10 минут или состояние очереди узнать не удалось |
| Планировщик | на боевом сайте `schedule:run` не запускался дольше 10 минут (или ни разу): в cron нужна строка `* * * * * cd /путь/к/сайту && php artisan schedule:run >> /dev/null 2>&1`. Время запуска пакет запоминает в кеше приложения (с драйвером `array` оно не сохраняется). На локальной машине строка только показывает время |
| Упавшие задачи | в журнале упавших задач очереди есть записи: `php artisan queue:failed` (строка есть, если журнал упавших задач умеет считать и доступен) |
| Соединение с базой | база не ответила на простой запрос — критично |
| Почта | на боевом сайте `log`/`array`: письма не уходят |
| Ссылка `storage` | нет `public/storage`: `php artisan storage:link` |
| Запись в `storage` и `bootstrap/cache` | нет прав — критично |
| Свободное место | меньше 15 % — предупреждение; меньше 5 % или 1 ГБ — критично |
| `post_max_size` | меньше `upload_max_filesize`: большие файлы не загрузятся |
| OPcache | на боевом сайте выключен |

**Свои проверки сайта.** Проверки, добавленные через `Fastleo::healthCheck()` ([softnetica.md](softnetica.md#свои-проверки-сайта)), выводятся в виджете отдельной колонкой «Проверки сайта»: название, текст результата и цвет (`warning` — предупреждение, `failed` — критично). Замыкания выполняются при каждом открытии дашборда, поэтому они должны быть быстрыми; сбой одной проверки не мешает остальным. Тексты в виджете показываются как есть (адреса и почта не прячутся — в отчёте для SoftNetica они скрываются).

Проверки «боевого сайта» на локальной машине не пугают: они включаются только при `APP_ENV=production`.

### Очистить кеш

Кнопка в карточке выполняет `cache:clear` (кеш приложения), `view:clear` (скомпилированные шаблоны) и `fastleo:clear` (список разделов и кеш настроек) и сообщает, сколько места освободилось (считаются файлы на диске; кеш Redis и базы данных в размер не входит). Нажатие подтверждается окном; действие — POST с защитой CSRF, по умолчанию доступно любому администратору; чтобы ограничить, опишите Gate `clearFastleoCache` — кнопка тогда пропадёт у остальных, а запрос получит ответ 403:

```php
Gate::define('clearFastleoCache', fn (User $user) => $user->is_owner);
```

Кеши конфигурации и маршрутов (`config:cache`, `route:cache`, `event:cache`) кнопка **не трогает**: на боевом сайте они собираются при деплое, и без них сайт замедлился бы до следующего деплоя (а без файла `.env` сломался бы совсем). Нужна полная очистка — `php artisan optimize:clear` в консоли. После очистки кеша приложения и шаблонов сайт на время пересоберёт их и может ответить медленнее.

## SoftNetica — статус от сервиса обслуживания

Статус и доступность сайта, бэкап этой ночи, ближайшие сроки SSL и домена, долг или ближайший платёж, ссылка «Подробнее» на раздел «SoftNetica». Виден только на подключённом сайте; без токена его нет. Подробности — [подключение к SoftNetica](softnetica.md).

## Свой виджет

Наследуйте `Fastleo\Widgets\Widget`: `view()` возвращает Blade-шаблон, `payload()` — данные для него. Карточку (рамку и заголовок) рисует дашборд, шаблон выводит только содержимое:

```php
final class QueueSize extends \Fastleo\Widgets\Widget
{
    public function view(): string
    {
        return 'widgets.queue-size';          // resources/views/widgets/queue-size.blade.php сайта
    }

    protected function payload(): array
    {
        return ['jobs' => DB::table('jobs')->count()];
    }
}
```

В шаблоне доступны ключи `payload()` как переменные; рамку-карточку с заголовком рисует сам дашборд — внутри шаблона берите готовые компоненты (`button`, `icon`). Классы Tailwind из шаблонов сайта в CSS админки не попадают (CSS собран заранее), поэтому для разметки берите компоненты пакета или свои стили.

Свой набор виджетов: `php artisan fastleo:make-dashboard` создаёт класс `Dashboard` (`app/Fastleo/Dashboard.php`) с виджетами по умолчанию — пакет находит его сам. Заготовка класса и шаблона виджета: `php artisan fastleo:make-widget QueueSize` (создаёт `app/Fastleo/Widgets/QueueSize.php` и `resources/views/fastleo/widgets/queue-size.blade.php`; подключается в `widgets()` класса `Dashboard`).
