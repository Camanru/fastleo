# Документация fastleo

Fastleo — пакет Laravel для работы с моделями Eloquent: панель сайта, CRM или внутренний бэк-офис. Он работает рядом с сайтом (`/fastleo`), на своём поддомене или как всё приложение на корне домена ([где разместить](configuration.md#адрес)).

Разделы в порядке, в котором их удобно читать: сначала установка и первый раздел панели, затем возможности по мере надобности.

## Начало

1. [Установка и обновление](installation.md) — пакет, модель пользователя, миграции, первый пользователь.
2. [Разделы (ресурсы)](resources.md) — первый раздел: миграция, модель и класс-ресурс.
3. [Поля](fields/README.md) — все типы полей и общие методы.
4. [Права доступа](authorization.md) — Policy моделей: кто что может в разделе. [Роли пользователей](roles.md) — регистратор, редактор, наблюдатель.
5. [Работа с Claude](claude.md) — раздел одной фразой и команды `fastleo:doctor`, `fastleo:inspect`, `fastleo:make-*`.
6. [Готовые модули сайта](modules.md) — `fastleo:module`: готовые разделы панели (контакты, страницы, новости, меню сайта, отзывы, портфолио, вопросы и ответы, услуги, прайс-лист, команда, филиалы и адреса, лицензии и сертификаты, партнёры и клиенты, интернет-магазин) копируются в проект вместе с публичной частью сайта (маршруты, контроллеры, простые шаблоны), если вы согласитесь. [Заявки](leads.md) — встроенный раздел: форма на сайте и приём с других сайтов по API с ключами.
