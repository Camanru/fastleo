# Раскладка формы

Поля в `fields()` можно группировать: вкладки, секции, колонки, боковая панель. Раскладка влияет только на форму — список и запись в базу от неё не зависят.

```php
use Fastleo\Layout\Aside;
use Fastleo\Layout\Grid;
use Fastleo\Layout\Section;
use Fastleo\Layout\Tab;
use Fastleo\Layout\Tabs;

public function fields(): array
{
    return [
        Tabs::make([
            Tab::make('Основное', [
                Text::make('title', 'Заголовок')->required(),
                Grid::make(3, [
                    Select::make('status', 'Статус')->options(ArticleStatus::class),
                    Number::make('views', 'Просмотры')->integer(),
                    Number::make('price', 'Цена')->step(0.01),
                ]),
            ]),
            Tab::make('Контакты', [
                Section::make('Автор', [
                    Email::make('author_email', 'Email'),
                    Tel::make('phone', 'Телефон'),
                ])->description('Не показывается на сайте'),
            ]),
        ]),
        Aside::make([
            Toggle::make('is_published', 'Опубликовано'),
            Date::make('published_on', 'Дата публикации'),
        ]),
    ];
}
```

Контейнеры можно вкладывать друг в друга: сетка в секции, секция во вкладке. Контейнер, в котором нет ни одного видимого поля (например, все поля `hideOnCreate()`), не выводится.

Имена полей должны быть уникальны во всей форме, даже в разных вкладках.

## Tabs и Tab

```php
Tabs::make([
    Tab::make('Основное', [/* поля */]),
    Tab::make('SEO', [/* поля */]),
]);
```

Открыта первая вкладка. Если после сохранения есть ошибки, открывается первая вкладка с ошибкой, а у вкладок с ошибками появляется красная точка. Внутри `Tabs` — только `Tab`, иначе ошибка PHP.

## Section

```php
Section::make('Контакты', [/* поля */])
    ->description('Показываются в подвале сайта')
    ->collapsible();
```

| Метод | Что делает |
|---|---|
| `description('Текст')` | Пояснение под заголовком |
| `collapsible()` | Секцию можно свернуть кнопкой в заголовке |
| `collapsed()` | Секция свёрнута при открытии формы (если в форме нет ошибок) |

## Grid

```php
Grid::make(3, [
    Text::make('city', 'Город')->columnSpan(2),
    Text::make('zip', 'Индекс'),
]);
```

Поля в несколько колонок (от 1 до 12). На телефоне — всегда одна колонка. Ширину поля задаёт `columnSpan()` у поля: сколько колонок сетки оно занимает (не больше числа колонок сетки).

## Aside

```php
Aside::make([
    Toggle::make('is_active', 'Показывать на сайте'),
    Date::make('published_on', 'Дата публикации'),
]);
```

Боковая панель справа от формы (на телефоне — под ней). Подходит для статуса, дат, галочек. Указывается на верхнем уровне `fields()`; панелей может быть несколько — они идут друг под другом.

## Зависимые поля

Поле можно показывать только при нужном значении другого поля формы:

```php
Select::make('type', 'Вид')->options(['news' => 'Новость', 'video' => 'Видео', 'promo' => 'Акция']),
Url::make('video_url', 'Ссылка на видео')->required()->visibleWhen('type', 'video'),
Date::make('promo_until', 'Акция до')->visibleWhen('type', ['promo', 'sale']),

Checkbox::make('is_featured', 'На главной'),
DateTime::make('featured_from', 'На главной с')->visibleWhen('is_featured', true),
```

- Значения: строка, число, `true`/`false` (для `Checkbox`/`Toggle`), backed enum или список из них.
- Управляющее поле — поле **одного значения**: `Select`, `Radio`, `Enum`, `Checkbox`/`Toggle`, `BelongsTo`, текстовые поля. Поле с несколькими значениями (`Select::multiple()`, `Tags`, `BelongsToMany`) — ошибка описания.
- Поле появляется и прячется сразу при изменении управляющего поля.
- Скрытое поле **не проверяется и не сохраняется** — `required()` у него не мешает отправке, значение в базе остаётся прежним. На сервере это правило Laravel `exclude_unless`, поэтому подставить скрытое поле запросом тоже нельзя.
- На странице просмотра поле видно, только если условие выполняется для сохранённой записи.
- Внутри вложенных блоков ([HasMany](fields/has-many.md)) условие смотрит на поле **того же блока**.

## Зависимые списки

Варианты списка могут зависеть от другого поля формы: «Город» от «Региона», «Модель» от «Марки». При смене поля-зависимости выбор сбрасывается, а варианты запрашиваются с сервера.

```php
// Связь: замыкание получает запрос вариантов и значение поля (null, если не выбрано)
BelongsTo::make('region_id', 'Регион'),
BelongsTo::make('city_id', 'Город')
    ->dependsOn('region_id', fn (Builder $query, mixed $region) => $query->where('region_id', $region ?? 0)),

// Select: замыкание вариантов получает значение поля
Select::make('brand', 'Марка')->options(['bmw' => 'BMW', 'kia' => 'Kia']),
Select::make('model', 'Модель')
    ->options(fn (?string $brand) => match ($brand) {
        'bmw' => ['x5' => 'X5', 'm3' => 'M3'],
        'kia' => ['rio' => 'Rio'],
        default => [],
    })
    ->dependsOn('brand'),
```

Замыкание получает значение зависимости так, как его отправляет форма: строкой (`'5'`, значение enum, `'1'`/`'0'` у галочки) или `null`, если ничего не выбрано.

Если управляющее поле админ менять не может (`readonly()`, `disabled()`, скрыто), условие и зависимость берут его **сохранённое** значение, а не присланное в запросе.

Уже сохранённое значение зависимого поля остаётся выбранным в форме и проходит проверку, пока значение зависимости не изменили, даже если вариантов под него уже нет (запись в корзине, список вариантов изменился). Как только зависимость сменили, сохранённое значение проверяется заново, как любое другое.

**Проверка** берёт значение зависимости из той же формы: город другого региона или модель другой марки сохранить нельзя. Зависимость — поле верхнего уровня формы; внутри вложенных блоков зависимые списки не работают (ошибка описания). Варианты для смены зависимости выдаёт `GET /fastleo/{раздел}/options/{поле}?depends=значение` с теми же правами, что и поиск по связям.

## Форма создания, заполненная из ссылки

Адрес `…/clients/create?prefill[phone]=79001234567&prefill[title]=Иван` открывает форму создания с уже заполненными полями: так делают ссылки «Создать клиента по этому номеру» или «Добавить заявку этому клиенту» (`route('fastleo.resources.create', ['resource' => 'offers', 'prefill' => ['client_id' => $client->id]])`).

- Заполняются только простые поля, которые администратор видит и может менять: текст, число, дата, время, цвет, список (без множественного выбора) и `BelongsTo`. Пароли, файлы, галочки, теги, вложенные записи, многоязычные, зависимые (`dependsOn()`) и скрытые (`Hidden`) поля не заполняются (поле с `visibleWhen()` заполняется; значение всё равно проверяется при сохранении): администратор не видит их значение и не заметил бы подмены.
- Значение попадает в форму, только если его пропустила бы проверка поля: вариант из списка, запись, доступная в `query()` поля, подходящая дата, длина в пределах `maxLength()`. Остальное молча пропускается — подставить в форму то, что администратору недоступно, нельзя.
- Это только предзаполнение: при сохранении форма проверяется как обычно. Значения, которые администратор уже ввёл (форма вернулась с ошибками), важнее ссылки; значения по умолчанию поля и колонок базы — слабее.
- Право `create` проверяется как всегда: без него форма не открывается.

## Кнопки формы

Под формой — закреплённая панель:

- **Сохранить** — сохранить и остаться в форме (Ctrl+S или Cmd+S);
- **Сохранить и выйти** — сохранить и вернуться к списку;
- **Сохранить и создать ещё** — только при создании: сохранить и открыть пустую форму.

Если в форме есть несохранённые изменения, браузер переспросит перед уходом со страницы. Удаление записи подтверждается в окне админки.
