# Файлы

В админке есть файловый менеджер: пункт меню «Файлы» (`/fastleo/files`). Он работает с одной папкой на диске Laravel Storage — по умолчанию `storage/app/public/uploads`, на сайте это адреса `/storage/uploads/...`.

## Что умеет менеджер

- папки и хлебные крошки, переход по папкам;
- загрузка кнопкой «Загрузить» и перетаскиванием файлов в окно (несколько сразу);
- новая папка (имя приводится к латинице, цифрам и дефису: «Новости 2026» → `novosti-2026`);
- выбор и удаление выбранного (папки удаляются со всем содержимым, после подтверждения);
- фильтр по имени;
- копирование ссылки и открытие файла в новой вкладке;
- миниатюры картинок (создаются при первом показе).

Под кнопками видны лимиты загрузки PHP: файл больше лимита не отправляется, админ сразу видит, какой файл не прошёл.

Переименования и переноса нет: записи и тексты, где стоит старый путь, перестали бы показывать файл.

Файлы не удаляются сами — ни при удалении записи, ни при замене картинки в поле: один файл может стоять в нескольких записях и в тексте статьи. Лишнее удаляется в менеджере.

## Настройка

Ключи `files.*` и `images.*` в `config/fastleo.php` — в [настройках](configuration.md#файлы).

Диск по умолчанию — `public`. Сайту нужна ссылка на него:

```bash
php artisan storage:link
```

Для S3 или Cloudflare R2 опишите диск в `config/filesystems.php` (с `url` для публичных адресов) и укажите его:

```php
// config/fastleo.php
'files' => [
    'disk' => 's3',
    'root' => 'uploads',
],
```

Права на менеджер — у всех, кто может войти в админку (`canAccessFastleo()`). Раздел «Файлы» (пункт меню, страница менеджера и удаление файлов) можно оставить части администраторов Gate `manageFastleoFiles`:

```php
Gate::define('manageFastleoFiles', fn (User $user) => $user->is_owner);
```

Когда Gate описан и запрещает, пункта «Файлы» в меню нет, страница менеджера и удаление отвечают 403. Остальным администраторам по-прежнему доступно то, без чего не заполнить поля: окно выбора файла в `Image`, `File`, `Gallery` и редакторе, загрузка, создание папки и обрезка картинки. Без Gate всё доступно любому администратору.

## Имена файлов

Имя файла при загрузке приводится к безопасному виду:

| Загрузили | Сохранено |
|---|---|
| `Фото врача.JPG` | `foto-vracha.jpg` |
| `Прайс (2026).pdf` | `prays-2026.pdf` |
| `shell.php.txt` | `shell-php.txt` — точки внутри имени заменяются, чтобы сервер не принял файл за скрипт |
| второй `foto-vracha.jpg` | `foto-vracha-1.jpg` — существующий файл не перезаписывается |

Имена папок — так же: `Новости 2026` → `novosti-2026`.

## Картинки

Картинки (`files.images`) при загрузке:

1. проверяются по заголовку файла: не картинка или больше `files.max_pixels` (32 мегапикселя; у анимированного GIF считаются все кадры) — не загружается, не открываясь;
2. открываются и пересохраняются: поворот по EXIF (фото с телефона не лежит на боку), без метаданных — в том числе без координат GPS;
3. уменьшаются до `images.max_width` (2560 пикселей), если шире.

Файл с расширением картинки, который не открывается как картинка, не сохраняется.

Поле [Image](fields/image.md) с `crop('3:4')` даёт обрезать картинку рамкой: получается копия `photo-crop.jpg` рядом с оригиналом, оригинал не меняется.

## Картинки для сайта: варианты и `<x-fastleo::picture>`

Чтобы сайт не отдавал телефону фото на 3 МБ, fastleo создаёт уменьшенные копии картинок в WebP — **варианты**. Размеры описываются в конфиге по имени:

```php
// config/fastleo.php
'images' => [
    'presets' => [
        'card' => ['widths' => [400, 800], 'ratio' => '4:3'],
        'photo' => ['widths' => [480, 1200], 'ratio' => null, 'watermark' => true],
    ],
],
```

| Ключ размера | Что делает |
|---|---|
| `widths` | Ширины вариантов в пикселях. Ширины больше картинки не создаются — вместо них один вариант размером с картинку |
| `ratio` | Пропорция `'ширина:высота'`: картинка обрезается по центру (например, квадрат `'1:1'`). `null` — без обрезки |
| `watermark` | `true` — на варианты ставится водяной знак (ниже) |

Поле выбирает размеры:

```php
Image::make('photo', 'Фото')->variants('card');
Gallery::make('photos', 'Фото клиники')->variants('photo');
```

После сохранения записи для **новых** картинок поля варианты создаются в очереди (без очереди — сразу, просто сохранение дольше; см. [установку](installation.md)). Внутри вложенных блоков (HasOne, HasMany) — тоже.

Вывод на сайте:

```blade
<x-fastleo::picture :src="$doctor->photo" preset="card" alt="{{ $doctor->name }}" sizes="(min-width: 768px) 400px, 100vw" class="rounded-lg" />
```

```html
<picture>
    <source type="image/webp" srcset="…/card/uploads/doctors/ivanov.jpg/400.webp 400w, …/800.webp 800w" sizes="(min-width: 768px) 400px, 100vw">
    <img src="/storage/uploads/doctors/ivanov.jpg" alt="Иванов И. И." width="800" height="600" loading="lazy" decoding="async" class="rounded-lg">
</picture>
```

- Пока вариантов нет (очередь ещё не дошла) — выводится просто `<img>` с оригиналом.
- `sizes` — какой ширины картинка на странице (по умолчанию `100vw`): по нему браузер выбирает вариант.
- Остальные атрибуты (`class`, `loading="eager"`, `fetchpriority="high"` для первого экрана) уходят в `<img>`.
- Пустой `src` — компонент ничего не выводит. Неизвестный `preset` — ошибка.
- Какие варианты есть, компонент берёт из кеша Laravel (после `cache:clear` — один раз читает файл описания с диска), поэтому показ не делает запросов к S3.

Варианты лежат на том же диске вне корня загрузок: `fastleo/variants/card/uploads/doctors/ivanov.jpg/400.webp`. При удалении картинки в менеджере удаляются и они. Создавать варианты по адресу «на лету» пакет не умеет специально: такой адрес позволил бы любому посетителю нагрузить сервер.

### Водяной знак

```php
'images' => [
    'watermark' => [
        'path' => 'uploads/watermark.png', // картинка в файловом менеджере, лучше PNG с прозрачностью
        'position' => 'bottom-right',      // top-left, top-right, bottom-left, bottom-right, center
        'opacity' => 50,                   // непрозрачность, %
        'size' => 20,                      // ширина знака, % от ширины варианта
    ],
],
```

Знак ставится **только на варианты** размеров с `'watermark' => true`. Оригинал остаётся чистым: знак можно поменять или убрать в любой момент.

### Пересоздать варианты

Поменяли размеры, пропорцию или водяной знак — пересоздайте варианты всех картинок всех полей с `variants()`:

```bash
php artisan fastleo:images
php artisan fastleo:images --preset=card   # только один размер
```

Команда работает без очереди и показывает, сколько картинок обработано.

## Безопасность

- Все пути из запроса проверяются по частям: `..`, `\`, пустые части (`uploads//`), скрытые файлы (`.env`, `.htaccess`) и всё вне корня отклоняются. Удалить сам корень нельзя.
- Загружать можно только расширения из `files.extensions`; `php`, `phtml`, `phar`, `html`, `svg`, `js`, `xml`, `htaccess` и другие исполняемые форматы запрещены всегда.
- Права на новые папки задаёт диск (у диска `public` Laravel — `0755`, другие пользователи сервера не могут в них писать).
- Изменяющие действия — POST/DELETE с CSRF.
- Служебные копии (миниатюры менеджера) лежат вне корня, в `fastleo/` на том же диске; при удалении файла удаляются и они.

Совет для nginx: запретите выполнение PHP в папке загрузок, даже если её заняли бы чужие файлы:

```nginx
location ^~ /storage/ {
    location ~ \.php$ { return 403; }
}
```

## Окно выбора

Поля картинок и файлов, а также редактор [RichText](fields/rich-text.md) открывают менеджер в окне выбора — та же страница без меню (`/fastleo/files?picker=field`). Если за это время сессия истекла, в окне появится «Войти в новой вкладке»: после входа вернитесь в форму и повторите выбор — введённое в форме не пропадёт.
