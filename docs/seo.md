# SEO и карта сайта

Три части: поле [`Seo`](fields/seo.md) в админке, компонент `<x-fastleo::seo>` в шаблоне сайта и `/sitemap.xml`.

## Поле в разделе

```php
// app/Fastleo/ArticleResource.php
use Fastleo\Fields\Seo;
use Fastleo\Layout\Tab;
use Fastleo\Layout\Tabs;

public function fields(): array
{
    return [
        Tabs::make([
            Tab::make('Статья', [/* поля статьи */]),
            Tab::make('SEO', [Seo::make('seo')]),
        ]),
    ];
}
```

Колонка и каст модели — в [описании поля](fields/seo.md).

## Теги на странице

В `<head>` шаблона записи:

```blade
<x-fastleo::seo :model="$article" :title="$article->title" :description="$article->body" :image="$article->cover" type="article" />
```

Компонент выводит `<title>`, `description`, `canonical`, `robots`, Open Graph (`og:*`) и `twitter:card`. Не дублируйте эти теги в шаблоне — уберите свой `<title>`.

| Атрибут | По умолчанию | Что задаёт |
|---|---|---|
| `model` | — | Запись с полем Seo; без неё берутся только остальные атрибуты |
| `field` | `seo` | Имя колонки с полем Seo |
| `title` | — | Заголовок, если в поле Seo он пуст |
| `description` | — | Описание. Можно передать HTML текста записи: теги, заголовки, скрипты уберутся, длина — до 160 знаков с обрезкой по слову |
| `image` | — | Путь картинки на диске загрузок или адрес `https://…` |
| `canonical` | текущая страница | Адрес `https://…` или путь `/…` |
| `type` | `website` | Тип Open Graph: `website`, `article`, `product`… |

**Откуда берётся значение.** Заголовок: поле Seo → атрибут `title` → название сайта (`APP_NAME`). Описание: поле Seo → атрибут `description` (очищенный). Картинка: поле Seo → атрибут `image`. Запрет индексации (`<meta name="robots" content="noindex">`) — только из поля Seo.

**Безопасность.** Значения экранируются. Адрес `canonical` и картинки строится от `APP_URL`, а не от заголовка `Host` запроса, — подменённый хост не попадёт в выдачу. У canonical нет параметров запроса (`?utm_…`, `?page=2`): страница в поиске одна. В картинке допускаются только `http(s)://` и пути на диске; `javascript:`, `data:` и `//host` отбрасываются.

Нужны значения в коде, а не готовые теги: `Fastleo\Support\SeoTags::resolve($article, title: …, description: …)` возвращает массив `title`, `description`, `image`, `canonical`, `noindex`, `type`, `site`.

## Карта сайта

`/sitemap.xml` — публичная карта для поисковиков, без входа. Включается в `config/fastleo.php`:

```php
'sitemap' => [
    'enabled' => true,
    'cache_minutes' => 60,
    'urls' => ['/contacts', ['loc' => '/about', 'lastmod' => '2026-01-31']],
],
```

Пока `enabled` выключено, маршрута нет вообще, и адрес `/sitemap.xml` свободен для вашего кода или файла. Маршрут подключается при старте приложения, поэтому после включения (или при `route:cache`) перезапустите/пересоберите кеш маршрутов.

**Какие разделы попадают в карту** — только те, где ресурс явно описал `sitemap()`. Оба метода пишутся в классе ресурса: `url()` — адрес записи на сайте, `sitemap()` — какие записи попадают в карту.

```php
// app/Fastleo/ArticleResource.php
use Illuminate\Database\Eloquent\Builder;
use Illuminate\Database\Eloquent\Model;

public function url(Model $record): string
{
    return route('articles.show', $record);
}

public function sitemap(Builder $query): Builder
{
    return $query->where('is_published', true);
}
```

`sitemap()` получает запрос по всем записям модели (ограничение `query()` ресурса — для админки — здесь не применяется) и возвращает его сужённым; `null` — раздела в карте нет (так по умолчанию). Адрес записи — из `url()`; записи без адреса пропускаются. Дата `lastmod` — из `updated_at`. Записи с галочкой «Не показывать в поиске» в поле Seo и удалённые в корзину в карту не попадают.

**Правила карты.**

- Все адреса приводятся к домену `APP_URL` (по протоколу карты адреса — на одном домене с картой): берутся путь и параметры, домен подставляется свой.
- Адреса не повторяются. Больше 50 000 адресов (`per_file`) — карта сама делится на файлы, подробнее — [большие сайты](#большие-сайты).
- Готовая карта хранится в кеше `cache_minutes` минут (`0` — строить при каждом запросе). Кеш сбрасывается сразу, когда запись раздела, входящего в карту, сохранена, удалена или восстановлена через Eloquent — из админки, консоли или кода сайта. Массовые запросы (`Model::query()->update()`) событий не вызывают — карта обновится по истечении времени кеша.
- Укажите карту в `robots.txt`: `Sitemap: https://site.ru/sitemap.xml` (своим файлом или [robots.txt из пакета](#robotstxt)).

### Большие сайты

- В одном файле не больше 50 000 адресов (`per_file`). Если адресов больше, `/sitemap.xml` становится [индексом карт](https://www.sitemaps.org/protocol.html#index) со ссылками на файлы `/sitemap-1.xml`, `/sitemap-2.xml` и так далее, а поисковикам по-прежнему даётся один адрес — `/sitemap.xml`.
- Всего строится до 10 файлов (при `per_file` по умолчанию — 500 000 адресов), остальные адреса пропускаются.
- Сборка карты на 500 000 адресов занимает порядка 200 МБ памяти — на таком сайте поднимите `memory_limit` или держите карту поменьше.
- В кеше каждый файл лежит под своим ключом, чтобы значение не упиралось в предел кеша в базе (16 МБ).
- Пока адресов хватает на один файл, `/sitemap-1.xml` не существует (404). При включённой карте пакет занимает адреса `/sitemap.xml` и `/sitemap-1.xml` … `/sitemap-999.xml`.

## robots.txt

Пакет может отдавать `/robots.txt` сам — без файла в `public`. Включается в `config/fastleo.php`:

```php
'robots' => [
    'enabled' => true,
    'lines' => ['User-agent: *', 'Disallow: /cart'],
],
```

- Пока `enabled` выключено, маршрута нет, и адрес свободен для вашего кода или файла.
- Ответ — `text/plain`: строки `lines` по порядку, а если включена [карта сайта](#карта-сайта), внизу добавляется `Sitemap: https://site.ru/sitemap.xml` (домен из `APP_URL`).
- Адрес админки в файл не попадает: он закрыт от индексации заголовком `X-Robots-Tag: noindex, nofollow`, а строка `Disallow` с ним подсказала бы, где искать вход.
- Файл `public/robots.txt` веб-сервер отдаёт раньше Laravel: при включённой настройке удалите его (`fastleo:doctor` предупреждает, если он есть). Маршрут подключается при старте приложения, поэтому после включения (или при `route:cache`) пересоберите кеш маршрутов.
