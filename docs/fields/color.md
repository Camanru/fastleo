# Color

Цвет в HEX: вводится текстом или выбирается палитрой браузера.

```php
use Fastleo\Fields\Color;

Color::make('color', 'Цвет метки')->default('#4f46e5');
```

**Колонка:** `$table->string('color', 9)->nullable()`.

**Проверка:** `#rgb`, `#rgba`, `#rrggbb` или `#rrggbbaa`.

**В списке:** образец цвета и код. Значение из базы, не похожее на цвет, выводится обычным текстом.

**На сайте:** если выводите цвет в атрибут `style`, проверяйте его так же — значение могли записать в базу не через админку.
