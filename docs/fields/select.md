# Select

Выбор из списка: один вариант или несколько.

```php
use Fastleo\Fields\Select;

// Массив «значение => подпись»
Select::make('status', 'Статус')->options([
    'draft' => 'Черновик',
    'published' => 'Опубликовано',
])->required();

// PHP backed enum (enum X: string или int): подписи из метода label(), если он есть, иначе имена вариантов
Select::make('status', 'Статус')->options(ArticleStatus::class);

// Замыкание — вызывается один раз за запрос (форма, список, проверка)
Select::make('city', 'Город')->options(fn () => City::query()->orderBy('name')->pluck('name', 'id')->all());

// Несколько вариантов
Select::make('days', 'Дни приёма')->options([1 => 'Пн', 2 => 'Вт', 3 => 'Ср'])->multiple();
```

**Колонка:**

- один вариант — `$table->string('status', 20)` (или `integer` для числовых значений);
- несколько — `$table->json('days')->nullable()` и каст `'days' => 'array'` в модели.

Для enum добавьте каст: `'status' => ArticleStatus::class`.

```bash
php artisan make:enum App/Enums/ArticleStatus --string   # app/Enums/ArticleStatus.php
```

```php
enum ArticleStatus: string
{
    case Draft = 'draft';
    case Published = 'published';

    public function label(): string
    {
        return match ($this) {
            self::Draft => 'Черновик',
            self::Published => 'Опубликовано',
        };
    }
}
```

**Проверка:** выбрано значение из списка вариантов (подставить своё значение через запрос нельзя). Для `multiple()` — массив значений из списка без повторов. Уже сохранённое значение вне вариантов проверку проходит — [ниже](#сохранённое-значение-вне-вариантов).

**В списке:** подписи выбранных вариантов через запятую (с `badges()` — цветные метки, у `multiple()` по метке на вариант). Значение, которого нет среди вариантов, показывается как есть. Поиск (`searchable()`) идёт по сохранённому значению (`published`), а не по подписи.

| Метод | Что делает |
|---|---|
| `options([...])` | Варианты: массив, класс backed enum или замыкание |
| `multiple()` | Можно выбрать несколько; ничего не выбрано — сохраняется пустой массив |
| `placeholder('Выберите')` | Подпись пустого варианта (по умолчанию «—») |
| `emptyValue(0)` | Что записать вместо `null`, когда выбран пустой вариант: `0`, `'none'`, `''` ([подробнее](#нет-значения-не-null)) |
| `badges([...])` | Цветные метки статуса вместо текста в списке и на просмотре: `->badges(['new' => 'info', 'done' => 'success'])`; тона `success`, `warning`, `danger`, `info`, `neutral` ([подробнее](#цветные-метки)) |
| `dependsOn('brand')` | Зависимый список: замыкание вариантов получает значение поля `brand` ([layout.md](../layout.md#зависимые-списки)) |

Общие методы — [README](README.md#общие-методы).

## Цветные метки

`badges([...])` показывает выбранный вариант цветной меткой в списке и на просмотре.

- Тона: `success`, `warning`, `danger`, `info`, `neutral`. Неизвестный тон — ошибка описания.
- Вариант, которого нет в массиве, — `neutral`.
- Без массива тон берётся из метода `tone()` enum (см. [Enum](enum.md)).
- В форме, выгрузке и импорте ничего не меняется. Своё `formatUsing()` выключает метки.

## «Нет значения» не NULL

Если на сайте «без категории» хранится нулём, а пустая строка или `null` ломают шаблон:

```php
Select::make('category_id', 'Основная категория')->options($categories)->placeholder('Без основной')->emptyValue(0);
```

Пустой вариант записывает `0`. Дальше такое значение считается пустым:

- при открытии записи с `0` в форме выбран «Без основной» (а не лишний вариант «0»);
- в списке и выгрузке ячейка пустая;
- при импорте пустая ячейка и подпись «Без основной» дают `0`.

`emptyValue()` недоступен у `multiple()`; у `Enum` значение должно быть одним из вариантов перечисления. `required()` по-прежнему требует выбрать вариант.

## Сохранённое значение вне вариантов

Если в записи лежит значение, которого нет в `options()`, форма показывает его отдельным выбранным вариантом, а проверка его пропускает — запись сохраняется без потери значения. Так бывает со старыми данными, когда вариант убрали из списка или у зависимого списка сменилась зависимость.

**Подробности:**

- выбрали другой вариант — прежнее значение пропадает из формы;
- новое значение вне списка по-прежнему отклоняется;
- это работает у самих полей раздела; в подполях блоков (`Repeater`, `Blocks`, `HasMany`, `HasOne`) значение вне вариантов не сохраняется — добавьте его в `options()`;
- так сохраняется, например, `0` в `category_id`, если «без категории» в вариантах не описано; чтобы это значение было видно с понятной подписью, добавьте его в `options()` (или задайте `emptyValue(0)` — [выше](#нет-значения-не-null)).
