# Select

Выбор из списка: один вариант или несколько.

```php
use Fastleo\Fields\Select;

// Массив «значение => подпись»
Select::make('status', 'Статус')->options([
    'draft' => 'Черновик',
    'published' => 'Опубликовано',
])->required();

// PHP backed enum (enum X: string или int): подписи из метода label(), если он есть, иначе имена вариантов
Select::make('status', 'Статус')->options(ArticleStatus::class);

// Замыкание — вызывается один раз за запрос (форма, список, проверка)
Select::make('city', 'Город')->options(fn () => City::query()->orderBy('name')->pluck('name', 'id')->all());

// Несколько вариантов
Select::make('days', 'Дни приёма')->options([1 => 'Пн', 2 => 'Вт', 3 => 'Ср'])->multiple();
```

**Колонка:**

- один вариант — `$table->string('status', 20)` (или `integer` для числовых значений);
- несколько — `$table->json('days')->nullable()` и каст `'days' => 'array'` в модели.

Для enum добавьте каст: `'status' => ArticleStatus::class`.

```php
enum ArticleStatus: string
{
    case Draft = 'draft';
    case Published = 'published';

    public function label(): string
    {
        return match ($this) {
            self::Draft => 'Черновик',
            self::Published => 'Опубликовано',
        };
    }
}
```

**Проверка:** выбрано значение из списка вариантов (подставить своё значение через запрос нельзя). Для `multiple()` — массив значений из списка без повторов.

**Сохранённое значение вне вариантов.** Если в записи лежит значение, которого нет в `options()` (старые данные, вариант убрали из списка, у зависимого списка сменилась зависимость), форма показывает его отдельным выбранным вариантом, а проверка его пропускает — запись сохраняется без потери значения. Выбрали другой вариант — прежнее значение пропадает из формы. Новое значение вне списка по-прежнему отклоняется. Это работает у самих полей раздела; в подполях блоков (`Repeater`, `Blocks`, `HasMany`, `HasOne`) значение вне вариантов не сохраняется — добавьте его в `options()`. Так сохраняется, например, `0` в `category_id`, если «без категории» в вариантах не описано; чтобы это значение было видно с понятной подписью, добавьте его в `options()`.

| Метод | Что делает |
|---|---|
| `options([...])` | Варианты: массив, класс backed enum или замыкание |
| `multiple()` | Можно выбрать несколько; ничего не выбрано — сохраняется пустой массив |
| `placeholder('Выберите')` | Текст пустого варианта (по умолчанию «—») |
| `emptyValue(0)` | Что записать, когда выбран пустой вариант, вместо `null`: `0`, `'none'`, `''`. Подходит колонке, где «нет значения» хранится не как NULL. Такое значение в форме, списке и выгрузке считается пустым и не добавляется вариантом; для `required()`, `multiple()` и Enum — см. ниже |
| `dependsOn('brand')` | Зависимый список: замыкание вариантов получает значение поля `brand` ([layout.md](../layout.md#зависимые-списки)) |

**«Нет значения» не NULL.** Если на сайте категория «без категории» хранится нулём, а пустая строка или `null` ломают шаблон: `Select::make('category_id', 'Основная категория')->options($categories)->placeholder('Без основной')->emptyValue(0)`. Пустой вариант записывает `0`; при открытии записи с `0` в форме выбран «Без основной» (а не лишний вариант «0»), в списке и выгрузке ячейка пустая, при импорте пустая ячейка и подпись «Без основной» дают `0`. `emptyValue()` недоступен у `multiple()`; у `Enum` значение должно быть одним из вариантов перечисления.

**В списке:** подписи выбранных вариантов через запятую. Значение, которого нет среди вариантов, показывается как есть. Поиск (`searchable()`) идёт по сохранённому значению (`published`), а не по подписи.

Кнопки вместо списка — [Radio](radio.md), варианты из enum — [Enum](enum.md). Связь с записью другой таблицы (`category_id` → категория) — поле [BelongsTo](belongs-to.md).
