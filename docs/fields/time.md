# Time

Время без даты: часы и минуты.

```php
use Fastleo\Fields\Time;

Time::make('opens_at', 'Открытие')->default('09:00');
```

**Колонка:** `$table->time('opens_at')->nullable()`.

**Проверка:** формат `ЧЧ:ММ`. Секунды из базы в форме и списке не показываются.

**В списке:** `09:00`.

`default()` принимает и время (`now()`, Carbon) — оно приводится к `ЧЧ:ММ` в часовом поясе админки. При импорте из Excel подходит ячейка-время или текст `ЧЧ:ММ` и `ЧЧ:ММ:СС`.
