# Image

Одна картинка из [файлового менеджера](../files.md): фото врача, обложка статьи. В форме — превью и кнопки «Загрузить», «Выбрать из файлов», «Убрать». В списке — миниатюра, на просмотре — крупная миниатюра со ссылкой на файл.

```php
use Fastleo\Fields\Image;

Image::make('photo', 'Фото')
    ->directory('doctors')
    ->crop('3:4')
    ->required();
```

**Колонка:** `$table->string('photo')->nullable()`. Хранится путь относительно диска `fastleo.files.disk`: `uploads/doctors/ivanov.jpg`. Адрес на сайте — `Storage::disk('public')->url($doctor->photo)`; с вариантами — компонент `<x-fastleo::picture :src="$doctor->photo" preset="card" />`.

**Загрузить** — файл сразу попадает в менеджер, в папку `directory()` (папка создаётся сама), и выбирается в поле. Картинка при этом проверяется и пересохраняется (поворот по EXIF, без метаданных, не шире `images.max_width`) — подробно в [files.md](../files.md#картинки).

**Выбрать из файлов** — окно менеджера: открывается в папке текущей картинки (или в папке поля), показывает только картинки; клик по картинке выбирает её.

**Обрезать** (есть, если задан `crop()`) — окно с рамкой в нужной пропорции. Рамку можно подвинуть и изменить; по кнопке «Обрезать» рядом с картинкой появляется копия `photo-crop.jpg` (`photo-crop-1.jpg`, если такая уже есть), и поле выбирает её. Оригинал не меняется — к нему можно вернуться через «Выбрать из файлов».

**Проверка:** путь внутри корня загрузок (`fastleo.files.root`), без `..` и скрытых файлов, с расширением картинки. Подставить в форму чужой путь (`../.env`, файл вне `uploads`) нельзя. Есть ли файл на диске, не проверяется: файл, удалённый в менеджере, не мешает сохранить запись.

**Удаление:** при замене картинки или удалении записи файл остаётся в менеджере — его могут использовать другие записи.

| Метод | Что делает |
|---|---|
| `directory('doctors')` | Папка внутри корня загрузок для файлов, загруженных в этом поле. Выбрать можно файл из любой папки. Имя папки — строчная латиница, цифры и дефис (без `_` и заглавных букв), вложенность через `/`: `doctors/2026`. Другое имя сразу даёт `LogicException` при описании раздела |
| `extensions(['jpg', 'png'])` | Только эти форматы (из разрешённых картинок) |
| `crop('3:4')` | Кнопка «Обрезать» с рамкой в пропорции `ширина:высота` (`'1:1'`, `'16:9'`) |
| `variants('card')` | WebP-варианты для сайта размеров из `fastleo.images.presets`, вывод — `<x-fastleo::picture>` ([files.md](../files.md#картинки-для-сайта-варианты-и-x-fastleopicture)) |

Работает и внутри вложенных блоков [HasMany](has-many.md) / [HasOne](has-one.md). Несколько картинок — поле [Gallery](gallery.md).
