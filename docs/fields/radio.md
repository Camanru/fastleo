# Radio

Один вариант из нескольких кнопками-переключателями. Удобно, когда вариантов 2–5 и их надо видеть сразу.

```php
use Fastleo\Fields\Radio;

Radio::make('layout', 'Вид страницы')
    ->options(['wide' => 'Широкий', 'narrow' => 'Узкий'])
    ->default('wide')
    ->required();

// Варианты из enum или замыкания — как у Select
Radio::make('status', 'Статус')->options(ArticleStatus::class);
```

**Колонка:** `$table->string('layout', 20)->default('wide')`.

**Проверка:** значение из списка вариантов. Значение, уже сохранённое в записи, но не входящее в варианты, остаётся выбранной кнопкой (как у [Select](select.md)), пока его не заменят.

| Метод | Что делает |
|---|---|
| `options([...])` | Варианты: массив, класс backed enum или замыкание (как у [Select](select.md)) |

Несколько вариантов Radio не выбирает: `multiple()` — ошибка описания. Используйте `Select::make()->multiple()`. Зависимые варианты (`dependsOn()`) Radio тоже не поддерживает: вызов — ошибка описания (`LogicException`); используйте `Select` ([зависимые списки](../layout.md#зависимые-списки)).

**В списке:** подпись выбранного варианта.
