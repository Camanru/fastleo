# Radio

Один вариант из нескольких кнопками-переключателями.

```php
use Fastleo\Fields\Radio;

Radio::make('layout', 'Вид страницы')
    ->options(['wide' => 'Широкий', 'narrow' => 'Узкий'])
    ->default('wide')
    ->required();

// Варианты из enum или замыкания — как у Select
Radio::make('status', 'Статус')->options(ArticleStatus::class);
```

Удобно, когда вариантов 2–5 и их надо видеть сразу.

**Колонка:** `$table->string('layout', 20)->default('wide')`.

**Проверка:** значение из списка вариантов. Значение, уже сохранённое в записи, но не входящее в варианты, остаётся выбранной кнопкой (как у [Select](select.md#сохранённое-значение-вне-вариантов)), пока его не заменят.

**В списке:** подпись выбранного варианта.

| Метод | Что делает |
|---|---|
| `options([...])` | Варианты: массив, класс backed enum или замыкание (как у [Select](select.md)) |
| `badges([...])` | Цветные метки вместо текста в списке и на просмотре — как у [Select](select.md) |

Общие методы — [README](README.md#общие-методы).

**Чего Radio не умеет:**

- выбрать несколько вариантов: `multiple()` — ошибка описания; используйте `Select::make()->multiple()`;
- зависимые варианты: `dependsOn()` — ошибка описания (`LogicException`); используйте `Select` ([зависимые списки](../layout.md#зависимые-списки)).
