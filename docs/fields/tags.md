# Tags

Метки свободным вводом.

```php
use Fastleo\Fields\Tags;

Tags::make('keywords', 'Ключевые слова')
    ->suggestions(['акция', 'новинка', 'обзор'])
    ->maxTagLength(30);
```

Enter или запятая добавляет метку, × убирает, Backspace в пустом вводе убирает последнюю. Можно вставить сразу «акция, новинка».

**Колонка:** `$table->json('keywords')->nullable()` и **обязательно** каст в модели `'keywords' => 'array'`. Без каста сохранение остановится с понятной ошибкой.

**Проверка:** массив строк, каждая не длиннее `maxTagLength` (по умолчанию 50), всего не больше 100 меток.

**В списке:** метки через запятую.

**Поведение:** пробелы по краям меток обрезаются, пустые и повторы убираются. Убрать все метки — сохранится пустой массив `[]`.

| Метод | Что делает |
|---|---|
| `suggestions([...])` | Подсказки при вводе (можно ввести и другие) |
| `maxTagLength(30)` | Наибольшая длина одной метки (по умолчанию 50) |

Общие методы — [README](README.md#общие-методы).

Если метки — записи другой таблицы, используйте связь [BelongsToMany](belongs-to-many.md).
