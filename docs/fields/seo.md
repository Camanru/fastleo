# Seo

Заголовок, описание, картинка и запрет индексации для поисковиков и соцсетей в одном блоке формы.

```php
use Fastleo\Fields\Seo;

Seo::make('seo');                                    // подпись «SEO», картинки в uploads/seo
Seo::make('seo', 'Для поисковиков')->directory('articles');
```

**Колонка:** `$table->json('seo')->nullable()` и **обязательно** каст в модели `'seo' => 'array'`. Без каста сохранение остановится с понятной ошибкой.

**Проверка:** у каждого подполя своя — таблица [«В форме»](#в-форме) ниже.

**В списке:** не показывается. На странице просмотра — заголовок, описание и пометка «Скрыто от поисковиков». В Excel/CSV не выгружается.

## Хранение

Объект, в котором только заполненные значения:

```json
{"title": "Лечение зубов без боли", "description": "Современная анестезия…", "image": "uploads/articles/a.jpg", "noindex": true}
```

На сайте поле выводит компонент [`<x-fastleo::seo>`](../seo.md#теги-на-странице), а записи с `noindex` не попадают в [карту сайта](../seo.md#карта-сайта).

| Метод | Что делает |
|---|---|
| `make('seo')` | Имя поля можно не указывать — по умолчанию `seo`, подпись — «SEO» |
| `directory('articles')` | Папка картинки внутри корня загрузок (`fastleo.files.root`, по умолчанию `uploads`; [файлы](../files.md#настройка)): `uploads/articles` (по умолчанию `seo`). Имя папки — как у [Image](image.md) |

Общие методы — [README](README.md#общие-методы).

## В форме

| Подполе | Проверка | Подсказка |
|---|---|---|
| Заголовок | строка до 255 символов | Лучше до 60; пусто — возьмётся название записи |
| Описание | строка до 500 символов | Лучше до 160; пусто — возьмётся начало текста записи |
| Картинка для соцсетей | как у [Image](image.md): путь внутри корня загрузок | Пусто — картинка из `<x-fastleo::seo :image>` (например, обложка записи); без неё превью без картинки |
| Не показывать в поиске | галочка | Тег `noindex` и исключение из карты сайта |

Над подполями — счётчики длины заголовка и описания и превью сниппета поисковика; они обновляются при вводе. Лимит 60/160 — совет, а не запрет.

**Где работает.** В форме раздела и на странице [настроек](../settings.md). Внутри `Repeater`, `Blocks` и в мини-форме действий — нет (понятная ошибка при открытии раздела).
