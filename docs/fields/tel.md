# Tel

Телефон: вариант [Text](text.md), который на телефоне открывает цифровую клавиатуру.

```php
use Fastleo\Fields\Tel;

Tel::make('phone', 'Телефон')->placeholder('+7 900 000-00-00');
```

**Колонка:** `$table->string('phone', 32)->nullable()`.

**Проверка:** строка до 32 символов (меняется `maxLength()`). Формат номера не проверяется — сохраняется как введён. Строгий формат задайте правилом: `->rules(['regex:/^\+7\d{10}$/'])`.

**В списке:** номер как введён.

| Метод | Что делает |
|---|---|
| `maxLength(20)` | Наибольшая длина (по умолчанию 32) |

Общие методы — [README](README.md#общие-методы).
