# Checkbox

Галочка «да/нет».

```php
use Fastleo\Fields\Checkbox;

Checkbox::make('is_featured', 'Показывать на главной');
Checkbox::make('is_active', 'Показывать на сайте')->quickToggle();
```

**Колонка:** `$table->boolean('is_featured')->default(false)`. **Модель:** каст `'is_featured' => 'boolean'`.

**Проверка:** «да» или «нет». `required()` не заставляет ставить галочку (снятая — тоже значение); для обязательного согласия — `->rules(['accepted'])`.

**В списке:** значок-галочка с подписью «Да» или крестик с подписью «Нет».

Снятая галочка сохраняется как `false` (форма отправляет скрытое значение `0`).

| Метод | Что делает |
|---|---|
| `quickToggle()` | Значок в списке становится кнопкой, которая меняет значение без открытия формы ([подробно](toggle.md#быстрый-переключатель-в-списке)) |

Общие методы — [README](README.md#общие-методы).

Тот же смысл в виде переключателя — [Toggle](toggle.md).
