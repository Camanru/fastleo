# BelongsToMany

Связь «многие ко многим»: статья ↔ темы, врач ↔ услуги.

```php
use Fastleo\Fields\BelongsToMany;

BelongsToMany::make('topics', 'Темы');
```

В форме — выбор нескольких записей с поиском. Имя поля — **метод связи** модели.

**Колонка:** своей колонки нет — связь хранится в промежуточной (pivot) таблице. Миграция и метод модели:

```bash
php artisan make:migration create_article_topic_table
```

```php
// Миграция
Schema::create('article_topic', function (Blueprint $table) {
    $table->foreignId('article_id')->constrained()->cascadeOnDelete();
    $table->foreignId('topic_id')->constrained()->cascadeOnDelete();
    $table->primary(['article_id', 'topic_id']);
});

// Модель
public function topics(): BelongsToMany
{
    return $this->belongsToMany(Topic::class);
}
```

В `$fillable` ничего добавлять не нужно: связь сохраняется `sync()` после записи модели, в той же транзакции.

**Проверка:** массив ключей без повторов, каждый — запись из вариантов поля.

**В списке:** скрыто по умолчанию; с `showInList()` — подписи через запятую (подгружаются одним запросом). На странице просмотра — подписи через запятую.

**Поведение при сохранении:**

- выбранные записи становятся связанными, остальные отвязываются;
- связи с записями **вне вариантов поля** (скрытыми `query()` или удалёнными в корзину) не трогаются — сохранение формы их не потеряет;
- с `dependsOn()` уже сохранённая связь остаётся выбранной, даже если запись перестала подходить под зависимость; при смене поля-зависимости выбор сбрасывается, и такие связи отвязываются;
- убрать все — сохраняется пустой набор; поле, которого нет в запросе, не меняется.

Дополнительные колонки промежуточной таблицы (`price`, `sort`) поле не редактирует.

**Варианты, подпись и поиск по серверу** — как у [BelongsTo](belongs-to.md): до `fastleo.relations.preload` вариантов — все в странице, больше — поиск по серверу.

| Метод | Что делает |
|---|---|
| `titleColumn('name')` | Колонка связанной модели с подписью |
| `relation('themes')` | Метод связи, если он называется не как поле |
| `query(fn (Builder $query) => ...)` | Ограничить варианты (и то, что можно сохранить) |
| `dependsOn('region_id', fn (Builder $query, mixed $region) => ...)` | Зависимый список: варианты по значению другого поля формы ([layout.md](../layout.md#зависимые-списки)) |
