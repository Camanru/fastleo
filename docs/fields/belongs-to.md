# BelongsTo

Связь «принадлежит»: запись ссылается на запись другой таблицы — статья на категорию, врач на клинику.

```php
use Fastleo\Fields\BelongsTo;

BelongsTo::make('category_id', 'Категория')->required();
```

Имя поля — **колонка внешнего ключа** (`category_id`). Связь берётся из метода модели с тем же именем без `_id`:

```php
// Миграция
$table->foreignId('category_id')->nullable()->constrained()->nullOnDelete();

// Модель
#[Fillable(['title', 'category_id'])]
class Article extends Model
{
    public function category(): BelongsTo
    {
        return $this->belongsTo(Category::class);
    }
}
```

Колонка должна быть в `$fillable` (как у всех полей). Нет метода связи или он использует другую колонку — понятная ошибка описания.

**В форме:** список с поиском. Если вариантов не больше `fastleo.relations.preload` (100, [настройки](../configuration.md#связи)), все они в странице и поиск идёт сразу; если больше — по мере ввода запрашивается сервер (20 вариантов за раз). Необязательное поле можно очистить крестиком.

**Подпись записи:** колонка `title`, если она есть в `$fillable` связанной модели, иначе `name`, иначе ключ. Своя колонка — `titleColumn()`. Варианты идут по алфавиту подписи.

**Проверка:** выбранная запись существует и входит в варианты поля — подставить запросом другую (например, скрытую `query()`) нельзя. Для числовых ключей значение должно быть целым числом.

| Метод | Что делает |
|---|---|
| `titleColumn('short_name')` | Колонка связанной модели с подписью |
| `relation('writer')` | Метод связи, если он называется не как колонка без `_id` |
| `query(fn (Builder $query) => ...)` | Ограничить варианты (и то, что можно сохранить) |
| `dependsOn('region_id', fn (Builder $query, mixed $region) => ...)` | Зависимый список: варианты по значению другого поля формы ([layout.md](../layout.md#зависимые-списки)) |

```php
use Illuminate\Database\Eloquent\Builder;

// Только активные клиники, подпись — короткое название
BelongsTo::make('clinic_id', 'Клиника')
    ->titleColumn('short_name')
    ->query(fn (Builder $query) => $query->where('is_active', true));

// Автор — пользователь, связь author() с колонкой author_id
BelongsTo::make('author_id', 'Автор')->relation('author');
```

Записи связанной модели в корзине (SoftDeletes) в вариантах не появляются — работают глобальные скоупы модели. Если у записи уже сохранена связь с такой (или скрытой `query()`) записью, связь не теряется: в форме она видна с подписью-ключом, и сохранить форму можно, не меняя её.

**В списке:** подпись связанной записи; связи всех строк подгружаются одним запросом. Если связанная запись удалена, показывается значение ключа. `sortable()` сортирует по значению ключа, `searchable()` — тоже по ключу (поиск по подписи связи пока не поддерживается).

**Права:** список вариантов (`GET /fastleo/{раздел}/options/{поле}`) доступен тем, кто видит раздел (`viewAny`), и только для поля, которое можно менять в форме.
