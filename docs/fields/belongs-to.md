# BelongsTo

Связь «принадлежит»: запись ссылается на запись другой таблицы — статья на категорию, врач на клинику.

```php
use Fastleo\Fields\BelongsTo;
use Illuminate\Database\Eloquent\Builder;

BelongsTo::make('category_id', 'Категория')->required();

// Только активные клиники, подпись — короткое название
BelongsTo::make('clinic_id', 'Клиника')
    ->titleColumn('short_name')
    ->query(fn (Builder $query) => $query->where('is_active', true));

// Автор — пользователь, связь author() с колонкой author_id
BelongsTo::make('author_id', 'Автор')->relation('author');
```

Имя поля — **колонка внешнего ключа** (`category_id`). Связь берётся из метода модели с тем же именем без `_id` в camelCase: `category_id` → `category()`, `main_category_id` → `mainCategory()`.

**Колонка:** внешний ключ, `$table->foreignId('category_id')->nullable()->constrained()->nullOnDelete()`. Он должен быть в `$fillable` (как у всех полей), а у модели — метод связи:

```php
#[Fillable(['title', 'category_id'])]
class Article extends Model
{
    public function category(): BelongsTo
    {
        return $this->belongsTo(Category::class);
    }
}
```

Нет метода связи или он использует другую колонку — понятная ошибка описания.

**Проверка:** выбранная запись существует и входит в варианты поля — подставить запросом другую (например, скрытую `query()`) нельзя. Для числовых ключей значение должно быть целым числом.

**В списке:** подпись связанной записи; связи всех строк подгружаются одним запросом. Если связанная запись удалена, показывается значение ключа. `sortable()` и `searchable()` работают по значению ключа, а не по подписи.

**В форме:** список с поиском. Необязательное поле можно очистить крестиком. Как ищет список, зависит от числа вариантов:

- не больше `fastleo.relations.preload` (100, [настройки](../configuration.md#связи)) — все варианты уже в странице, поиск идёт сразу;
- больше — поле становится поиском по серверу: по мере ввода оно запрашивает варианты (20 за раз), а пустое поле ничего не предлагает.

**Подробности о пороге:**

- порог один на весь сайт; если нужен обычный список для таблицы на несколько сотен записей, поднимите `relations.preload`;
- `fastleo:doctor` пишет, у каких полей сработал поиск по серверу.

**Подпись записи:** колонка `title`, если она есть в `$fillable` связанной модели, иначе `name`, иначе ключ. Своя колонка — `titleColumn()`. Варианты идут по алфавиту подписи; если связанная модель — дерево (раздел с `$treeColumn`), варианты в странице идут деревом с отступами «— » ([resources.md](../resources.md#дерево)).

**Скрытые записи.** Записи связанной модели в корзине (SoftDeletes) в вариантах не появляются — работают глобальные скоупы модели. Если у записи уже сохранена связь с такой (или скрытой `query()`) записью, связь не теряется: в форме она видна с подписью-ключом, и сохранить форму можно, не меняя её.

**Права:** список вариантов (`GET /fastleo/{раздел}/options/{поле}`) доступен тем, кто видит раздел (`viewAny`), и только для поля, которое можно менять в форме.

| Метод | Что делает |
|---|---|
| `titleColumn('short_name')` | Колонка связанной модели с подписью |
| `relation('writer')` | Метод связи, если он называется не как колонка без `_id` |
| `query(fn (Builder $query) => ...)` | Ограничить варианты (и то, что можно сохранить) |
| `dependsOn('region_id', fn (Builder $query, mixed $region) => ...)` | Зависимый список: варианты по значению другого поля формы ([layout.md](../layout.md#зависимые-списки)) |
