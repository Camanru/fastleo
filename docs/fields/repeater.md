# Repeater

Повторяющаяся группа полей в одной JSON-колонке.

```php
use Fastleo\Fields\Image;
use Fastleo\Fields\Repeater;
use Fastleo\Fields\Text;
use Fastleo\Fields\Textarea;
use Fastleo\Layout\Grid;

Repeater::make('faq', 'Вопросы и ответы')
    ->fields([
        Grid::make(2, [
            Text::make('question', 'Вопрос')->required(),
            Image::make('icon', 'Иконка')->directory('faq'),
        ]),
        Textarea::make('answer', 'Ответ'),
    ])
    ->max(20);
```

Подходит для вопросов и ответов, этапов работ, преимуществ, строк прайса — когда отдельная таблица не нужна. Элементы добавляются кнопкой, удаляются корзиной и перетаскиваются за ручку.

**Колонка:** `$table->json('faq')->nullable()` и **обязательно** каст в модели `'faq' => 'array'`. Без каста сохранение остановится с понятной ошибкой.

**Проверка:** правила подполей — для каждого элемента («Заполните поле «Вопрос».» под полем элемента). Число элементов — `min()` / `max()` (по умолчанию не больше 100). Своё правило со ссылкой на соседнее подполе пишется с полным путём: `required_if:faq.*.type,video`.

**В списке:** не показывается (можно `showInList()`). На странице просмотра — таблица элементов. В Excel/CSV не выгружается.

## Хранение

Список объектов в порядке формы:

```json
[{"question": "Как записаться?", "icon": "uploads/faq/phone.png", "answer": "По телефону"}]
```

На сайте — обычный массив: `@foreach ($page->faq ?? [] as $item) {{ $item['question'] }} @endforeach`.

## Поведение

- В элемент попадают только описанные подполя — лишние ключи из запроса отбрасываются.
- Значения подполей обрабатываются как в форме: строки обрезаются, галочка — `true`/`false`, дата — `ГГГГ-ММ-ДД`.
- Новый элемент, в котором ничего не заполнено (или только значения по умолчанию), не сохраняется. Убрать все элементы — сохранится `[]`.
- Для новых картинок подполей `Image` и `Gallery` с `variants()` создаются варианты.

| Метод | Что делает |
|---|---|
| `fields([...])` | Подполя и раскладка (`Grid`, `Section`) элемента |
| `min(1)` | Не меньше стольких элементов (с `min` ≥ 1 поле обязательное) |
| `max(20)` | Не больше стольких элементов (по умолчанию 100) |

Общие методы — [README](README.md#общие-методы).

## Что можно положить в элемент

**Работают** простые поля: `Text`, `Textarea`, `Number`, `Select`, `Radio`, `Enum`, `Checkbox`, `Toggle`, `Date`, `DateTime`, `Time`, `Email`, `Url`, `Tel`, `Color`, `Range`, `Hidden`, `Tags`, `Code`, `Markdown`, файлы `Image`, `File`, `Gallery` и `RichText`, а также `visibleWhen()` по соседнему подполю.

**Не работают** (понятная ошибка при открытии раздела):

- связи, `HasMany`/`HasOne`;
- другие JSON-поля: `Repeater`, `Blocks`, `KeyValue`;
- `Slug`, `Password`;
- `dependsOn()`, `translatable()`;
- `hideOnCreate()`/`hideOnEdit()`/`hidden()`, `readonly()`/`disabled()` — элемент сохраняется заново из формы, и скрытое значение стёрлось бы.

Если элементы нужно искать, фильтровать или связывать с другими записями — используйте отдельную таблицу и [HasMany](has-many.md).
