# File

Один файл из [файлового менеджера](../files.md): прайс, договор, презентация.

```php
use Fastleo\Fields\File;

File::make('price', 'Прайс')
    ->extensions(['pdf', 'xlsx'])
    ->directory('prices');
```

**Колонка:** `$table->string('price')->nullable()`. Хранится путь относительно диска: `uploads/prices/prays-2026.pdf`. Адрес на сайте — `Storage::disk('public')->url($clinic->price)`.

**Проверка:** путь внутри корня загрузок (`fastleo.files.root`, по умолчанию `uploads`; [файлы](../files.md#настройка)), расширение — из `extensions()` (по умолчанию все разрешённые в `fastleo.files.extensions`). Исполняемые форматы (`php`, `html`, `svg`, `js`…) не разрешить ни в поле, ни в конфиге.

**В списке:** ссылка на файл (для картинки — миниатюра). На странице просмотра — ссылка или крупная миниатюра.

**В форме:** имя файла со ссылкой и кнопки «Загрузить», «Выбрать из файлов», «Убрать».

**Загрузить** — файл сразу попадает в менеджер, в папку `directory()`, и выбирается в поле. Имя приводится к безопасному виду (`Прайс 2026.pdf` → `prays-2026.pdf`), существующий файл не перезаписывается.

**Удаление:** при замене файла или удалении записи файл остаётся в менеджере.

**Размер:** наибольший размер файла — общий, `fastleo.files.max_size` или лимит PHP ([настройки](../configuration.md#файлы)).

| Метод | Что делает |
|---|---|
| `extensions(['pdf', 'xlsx'])` | Какие форматы принимает поле (из разрешённых в конфиге) |
| `directory('prices')` | Папка внутри корня загрузок для файлов, загруженных в этом поле. Имя папки — строчная латиница, цифры и дефис (без `_` и заглавных букв), вложенность через `/`: `doctors/2026`. Другое имя сразу даёт `LogicException` при описании раздела |

Общие методы — [README](README.md#общие-методы).
