# Secret

Секрет (токен бота, ключ API): пишется в модель как есть, а не хешем, но в форме не показывается; `required()` требует значение только при создании записи.

```php
use Fastleo\Fields\Secret;

Secret::make('api_key', 'Ключ API')->required();
```

В отличие от [Password](password.md), значение пишется в модель как есть, а не хешем — например, пароль от чужого сервиса. Поле в форме всегда пустое: сохранённое значение никогда не попадает на страницу.

**Колонка и модель:** `$table->text('api_key')` и каст `'api_key' => 'encrypted'` в модели — значение хранится зашифрованным ключом приложения. Колонку лучше добавить и в `$hidden` модели.

**Проверка:** строка до 1000 символов; свой формат — `rules()`:

```php
Secret::make('api_key', 'Ключ API')->rules(['regex:/^sk_[A-Za-z0-9]{32}$/']);
```

**В списке:** не показывается. Значения нет и на просмотре, в экспорте, в [журнале изменений](../activity.md) и через [MCP](../claude.md#mcp-сервер).

## Поведение

- При создании `required()` требует значение.
- При редактировании пустое поле оставляет прежнее (подсказка «Сохранено — оставьте пустым, чтобы не менять»), новое значение заменяет. `required()` здесь не требует ввода.
- Пробелы по краям обрезаются.

Общие методы — [README](README.md#общие-методы).

**Где не работает.** Как и Password, поле не работает внутри вложенных блоков, мини-форм действий и на страницах настроек (там секрет — метод `encrypted()` страницы, см. [настройки](../settings.md)).
