# Secret

Секрет: токен бота, ключ API, пароль от чужого сервиса — то, что нужно хранить как есть (а не хешем, как [Password](password.md)), но нельзя показывать. Поле в форме всегда пустое: сохранённое значение никогда не попадает на страницу.

```php
use Fastleo\Fields\Secret;

Secret::make('api_key', 'Ключ API')->required();
```

**Колонка и модель:** `$table->text('api_key')` и каст `'api_key' => 'encrypted'` в модели — значение хранится зашифрованным ключом приложения. Колонку лучше добавить и в `$hidden` модели.

**Поведение:**

- при создании `required()` требует значение;
- при редактировании пустое поле оставляет прежнее (подсказка «Сохранено — оставьте пустым, чтобы не менять»), новое значение заменяет;
- пробелы по краям обрезаются;
- в списке, на просмотре, в экспорте, в [журнале изменений](../activity.md) и через [MCP](../claude.md#mcp-сервер) значения нет.

**Проверка:** строка до 1000 символов; свой формат — `rules()`:

```php
Secret::make('api_key', 'Ключ API')->rules(['regex:/^sk_[A-Za-z0-9]{32}$/']);
```

| Метод | Что делает |
|---|---|
| `required()` | Обязателен только при создании записи |

Как и Password, поле не работает внутри вложенных блоков, мини-форм действий и на страницах настроек (там секрет — метод `encrypted()` страницы, см. [настройки](../settings.md)).
