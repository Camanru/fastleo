# Range

Число ползунком; текущее значение видно рядом. По умолчанию — целое от 0 до 100 с шагом 1.

```php
use Fastleo\Fields\Range;

Range::make('discount', 'Скидка, %')->min(0)->max(50)->step(5)->default(0);

// Дробное значение
Range::make('opacity', 'Прозрачность')->integer(false)->min(0)->max(1)->step(0.1);
```

**Колонка:** `$table->unsignedTinyInteger('discount')->default(0)` (для дробных — `decimal`).

**Проверка:** число в границах `min`–`max`.

| Метод | Что делает |
|---|---|
| `min(0)` / `max(100)` | Границы ползунка и проверки (по умолчанию 0 и 100) |
| `step(5)` | Шаг ползунка |
| `integer(false)` | Разрешить дробные значения |

Ползунок всегда отправляет значение, поэтому пустым поле не бывает: при создании без `default()` стоит нижняя граница.
