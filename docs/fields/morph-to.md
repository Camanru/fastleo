# MorphTo

Полиморфная связь «принадлежит»: запись ссылается на запись одного из нескольких разделов — заметка на статью или товар, отзыв на товар или магазин. В базе это две колонки: тип (`subject_type`) и ключ (`subject_id`).

```bash
php artisan make:model Remark -m          # модель и миграция таблицы remarks
php artisan fastleo:make-resource Remark  # ресурс раздела
```

```php
// database/migrations/…_create_remarks_table.php
Schema::create('remarks', function (Blueprint $table) {
    $table->id();
    $table->text('body');
    $table->nullableMorphs('subject');    // subject_type и subject_id; для uuid/ulid — nullableUuidMorphs() / nullableUlidMorphs()
    $table->timestamps();
});

// app/Models/Remark.php — обе колонки в $fillable и метод связи
use Illuminate\Database\Eloquent\Attributes\Fillable;
use Illuminate\Database\Eloquent\Relations\MorphTo;

#[Fillable(['body', 'subject_type', 'subject_id'])]
class Remark extends Model
{
    public function subject(): MorphTo
    {
        return $this->morphTo();
    }
}

// app/Fastleo/RemarkResource.php — в fields(); здесь MorphTo — поле fastleo, а не связь Eloquent
use Fastleo\Fields\MorphTo;
use Illuminate\Database\Eloquent\Builder;

MorphTo::make('subject', 'О чём')->types([
    ArticleResource::class,
    ProductResource::class => fn (Builder $query) => $query->where('is_visible', true),
]);
```

Имя поля — **метод `morphTo()` модели** (`subject`); если метод называется иначе — `->relation('commentable')`. Колонки (`subject_type`, `subject_id`) поле берёт из этого метода.

**Разделы-типы.** `types()` — классы ресурсов сайта. Выбрать можно запись только этих разделов: произвольный класс или раздел не из списка форма и поиск не принимают. После класса можно сузить выбор: `Класс::class => fn (Builder $query) => …`. Для выбора используется запрос раздела (`query()` ресурса и скоупы модели) плюс это сужение.

**Что записывается.** В колонку типа попадает `getMorphClass()` модели раздела: имя класса или псевдоним из `Relation::morphMap()`. Записи, сохранённые раньше под именем класса, поле узнаёт и при включённой карте. Если сайт включил `Relation::enforceMorphMap()`, модели всех типов должны быть в карте (`fastleo:doctor` это проверяет).

**Поиск записи** идёт по колонке `title`, затем `name` (если она есть в `$fillable` модели раздела), иначе по ключу; подпись берётся из `title()` ресурса. Если у модели раздела колонки названия другие (`full_name`), искать в форме придётся по ключу.

**В форме:** слева список разделов, справа выбор записи выбранного раздела с поиском по серверу; при смене раздела выбранная запись сбрасывается. В списке разделов только те, список которых администратору разрешено открывать (`viewAny` Policy и `Resource::can()`); обязательное поле без выбора не сохраняется.

**Проверка:** массив только из `type` (адрес раздела) и `id`; обе части вместе или обе пустые; раздел входит в `types()` и доступен администратору; запись есть в запросе раздела. Сохранённая пара записи проходит проверку без этого, только если не изменился ни тип, ни ключ: подставить к сохранённому ключу другой раздел нельзя.

**Сохранённое значение, которое выбрать нельзя** (раздел убран из `types()`, закрыт администратору, класса больше нет): форма выводит его текстом (`Статья #5`, `Old #5`), не отправляет и при сохранении не меняет (запрос, собранный вручную с пустой парой, у необязательного поля очистит её; пустая ячейка импорта такую пару не трогает); обязательность на такую запись не действует. Поле не создаёт класс по строке из базы, поэтому запись с неизвестным типом не ломает список и карточку.

**В списке и на просмотре:** «Статья: Заголовок» (заголовок — `title()` раздела) ссылкой на запись, если её можно открыть. Заголовок виден, только если раздел открыт администратору; иначе — «Статья #5». Записи всей страницы списка подгружаются одной выборкой на раздел; подписи видны всем, у кого есть `viewAny` раздела.

**Импорт и экспорт:** ячейка `адрес-раздела:ключ` (`articles:5`), делится по первому двоеточию. Проверки те же, что в форме.

**MCP:** значение — `{"type": "articles", "id": "5"}`; запись неизвестного типа и запись раздела, закрытого администратору, отдаётся как `{"type": null, "id": "5", "morph_class": "App\\Old"}`; принять обратно такое значение без изменений можно (колонки не трогаются), другое — нет. Выгрузка для таких записей даёт пустую ячейку.

**Нельзя** (ошибка описания): не заданы типы; класс не найден среди разделов сайта; два раздела одной модели; `sortable()`, `searchable()`, `inlineEditable()`, `dependsOn()`, `translatable()`, `emptyValue()`, `fromQuery()`. Поле нельзя использовать внутри блоков `HasMany`, `HasOne`, `Repeater`, `Blocks`, на страницах настроек и в формах действий; как управляющее поле `visibleWhen()` и `dependsOn()` оно не годится (ошибка описания). Фильтра списка для него нет.

**Права:** список вариантов (`GET /fastleo/{раздел}/options/{поле}?depends=адрес-раздела`) доступен тем, кто видит раздел с полем (`viewAny`), и только для поля, которое можно менять; раздел-тип вне `types()` или закрытый администратору отвечает 404.

| Метод | Что делает |
|---|---|
| `types([...])` | Разделы-типы, при необходимости с сужением выбора |
| `relation('commentable')` | Метод `morphTo()`, если он называется не как поле |
