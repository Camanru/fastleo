# KeyValue

Пары «название — значение» в одной JSON-колонке: характеристики товара, параметры, свойства.

```php
use Fastleo\Fields\KeyValue;

KeyValue::make('specs', 'Характеристики')
    ->keyLabel('Параметр')
    ->valueLabel('Значение')
    ->max(30);
```

**Колонка:** `$table->json('specs')->nullable()` и **обязательно** каст в модели `'specs' => 'array'`. Без каста сохранение остановится с понятной ошибкой. В MySQL `json` сортирует ключи — чтобы строки на сайте шли в порядке формы, возьмите `text` (см. «Порядок строк» ниже); в PostgreSQL `json` порядок сохраняет.

**Проверка:** название обязательно, если указано значение; названия не повторяются; название до 255 символов, значение до 65 535; не больше `max()` строк (по умолчанию 100).

**В списке:** не показывается (можно `showInList()`). На странице просмотра — «название: значение» построчно. В Excel/CSV не выгружается.

**В форме:** строки добавляются, удаляются и перетаскиваются.

**Хранение:** объект в порядке формы — `{"Вес": "1,5 кг", "Цвет": "белый"}`. На сайте:

```blade
@foreach ($product->specs ?? [] as $name => $value)
    <dt>{{ $name }}</dt><dd>{{ $value }}</dd>
@endforeach
```

**Поведение:** пробелы по краям обрезаются, совсем пустые строки отбрасываются, значение может быть пустым (`null`). Убрать все строки — сохранится `[]`.

**Подробности:**

- Названия не повторяются без учёта регистра и пробелов по краям: «Вес» и «вес» — одно название.
- Названия из одних цифр (`0`, `1`) поле сохраняет JSON-объектом, а не списком — при записи из формы и [MCP](../claude.md#mcp-сервер). Если сайт сам записывает в модель массив `[0 => …]`, JSON превратит его в список.

**Порядок строк.** В SQLite и MariaDB колонка `json` хранит строки в порядке формы. В PostgreSQL и MySQL некоторые типы колонок сортируют ключи объекта, и на сайте строки пойдут не в порядке формы:

- PostgreSQL: `jsonb` сортирует ключи — используйте `json`;
- MySQL: `json` сортирует ключи (по длине названия, затем по алфавиту) — используйте `$table->text('specs')->nullable()` с тем же кастом `array`.

| Метод | Что делает |
|---|---|
| `keyLabel('Параметр')` | Подпись столбца названий (по умолчанию «Название») |
| `valueLabel('Значение')` | Подпись столбца значений (по умолчанию «Значение») |
| `max(30)` | Не больше стольких строк (по умолчанию 100) |

Общие методы — [README](README.md#общие-методы).
