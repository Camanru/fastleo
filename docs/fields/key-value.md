# KeyValue

Пары «название — значение» в одной JSON-колонке: характеристики товара, параметры, свойства. Строки добавляются, удаляются и перетаскиваются.

```php
use Fastleo\Fields\KeyValue;

KeyValue::make('specs', 'Характеристики')
    ->keyLabel('Параметр')
    ->valueLabel('Значение');
```

**Колонка:** `$table->json('specs')->nullable()` и **обязательно** каст в модели `'specs' => 'array'`. Без каста сохранение остановится с понятной ошибкой.

**Хранение:** объект в порядке формы — `{"Вес": "1,5 кг", "Цвет": "белый"}`. На сайте:

```blade
@foreach ($product->specs ?? [] as $name => $value)
    <dt>{{ $name }}</dt><dd>{{ $value }}</dd>
@endforeach
```

Названия не повторяются без учёта регистра и пробелов по краям («Вес» и «вес» — одно название). Названия из одних цифр (`0`, `1`) сохраняются JSON-объектом, а не списком — так, когда запись идёт через поле (форма, импорт, MCP); значение, записанное моделью напрямую массивом `[0 => …]`, JSON превратит в список.

Порядок строк хранит не каждая колонка: `jsonb` в PostgreSQL и `json` в MySQL сортируют ключи объекта (MySQL — по длине названия, затем по алфавиту). Чтобы на сайте строки шли как в форме, в PostgreSQL используйте `json`, а в MySQL — `$table->text('specs')->nullable()` с тем же кастом `array`. В SQLite и MariaDB `json` порядок сохраняет.

**Поведение:** пробелы по краям обрезаются, совсем пустые строки отбрасываются, значение может быть пустым (`null`). Убрать все строки — сохранится `[]`.

**Проверка:** название обязательно, если указано значение; названия не повторяются; название до 255 символов, значение до 65 535; не больше `max()` строк (по умолчанию 100).

| Метод | Что делает |
|---|---|
| `keyLabel('Параметр')` | Подпись столбца названий (по умолчанию «Название») |
| `valueLabel('Значение')` | Подпись столбца значений (по умолчанию «Значение») |
| `max(30)` | Не больше стольких строк |

**В списке:** не показывается (можно `showInList()`). На странице просмотра — «название: значение» построчно. В Excel/CSV не выгружается.
