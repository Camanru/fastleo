# Code

Код или HTML-вставка: счётчик, виджет, код в `<head>`.

```php
use Fastleo\Fields\Code;

Code::make('head_code', 'Код в <head>')->rows(10)->help('Вставляется на страницу без изменений');
```

**Колонка:** `$table->text('head_code')->nullable()`.

**Проверка:** строка; с `maxLength()` — не длиннее заданного.

**В списке:** скрыто; с `showInList()` — первые 100 символов текстом. На странице просмотра — моноширинным блоком.

**В форме:** моноширинный шрифт, Tab вставляет отступ (Esc, затем Tab — перейти к следующему полю).

**Поведение:** HTML **не чистится** — значение сохраняется как введено. Обрезаются только пробелы по краям всего текста, отступы строк остаются. В админке значение всегда показывается текстом и не выполняется. На сайте выводите его сами и только там, где это задумано:

```blade
{!! $page->head_code !!}
```

Давайте доступ к таким полям только тем, кому доверяете (через [Policy](../authorization.md) или `hidden()`): вставленный скрипт выполнится у посетителей сайта.

| Метод | Что делает |
|---|---|
| `rows(10)` | Высота поля в строках (по умолчанию 10) |
| `maxLength(5000)` | Наибольшая длина |

Общие методы — [README](README.md#общие-методы).
