# Toggle

Переключатель «вкл/выкл». Работает как [Checkbox](checkbox.md), выглядит как тумблер.

```php
use Fastleo\Fields\Toggle;

Toggle::make('is_active', 'Показывать на сайте')->default(true);
```

**Колонка:** `$table->boolean('is_active')->default(true)`. **Модель:** каст `'is_active' => 'boolean'`.

**Значение в новой записи:** `default()` поля; если его нет — `$attributes` модели, затем DEFAULT колонки. Поэтому `->default(true)` в миграции достаточно: переключатель в форме создания будет включён, и `default(true)` в ресурсе не нужен (если он есть, он главнее колонки).

**Проверка:** «да» или «нет». Выключенный переключатель сохраняется как `false`. В списке — значок ✓ или «—».

## Быстрый переключатель в списке

`quickToggle()` превращает значок в списке в кнопку: клик меняет значение без открытия формы и без перезагрузки страницы — удобно, чтобы скрыть услугу на время.

```php
Toggle::make('menu', 'Показывать на сайте')->default(true)->quickToggle();
```

Сервер проверяет то же, что при сохранении формы: право `update` на запись (Policy), поле не `readonly()`, не скрыто (`hidden()`) и есть в форме редактирования (не `onlyInList()` и не `hideOnEdit()`), выполнено условие `visibleWhen()`, правила поля. Правила видят только значение переключателя и управляющее поле условия `visibleWhen()`; правила, которым нужны другие поля формы, здесь не сработают — для таких проверок переключатель не включайте. Запись идёт через Eloquent: observers работают, изменение попадает в журнал под именем администратора. Без права `update`, в разделе `$readonly`, в корзине, у `readonly()` поля и там, где условие `visibleWhen()` не выполнено, значок остаётся обычным; прямой запрос в этих случаях получает отказ 403. `fastleo:doctor` предупреждает про `quickToggle()` у поля, которого нет в форме редактирования. Если сервер отказал, значок остаётся прежним, рядом появляется сообщение.

Работает и в таблице, и в карточках на телефоне. Кнопка живёт по адресу `POST /fastleo/{раздел}/{id}/toggle/{поле}` (`route('fastleo.resources.toggle', [...])`, в теле `value` = `1` или `0`) и принимает только поля с `quickToggle()`. Если такое поле стоит первым столбцом, его ячейка не ссылается на форму записи. Есть и у [Checkbox](checkbox.md).

Показать или скрыть сразу много записей — готовые действия `SetToggle` ([действия](../actions.md#готовое-действие-показать--скрыть)).

Удобно класть в боковую панель формы — `Aside::make([Toggle::make('is_active')])` ([layout.md](../layout.md)).
