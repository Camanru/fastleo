# Slug

Адрес записи для сайта (`o-kompanii`): латиница в нижнем регистре, цифры и дефис.

```php
use Fastleo\Fields\Slug;

Slug::make('slug', 'Адрес')->from('title');
```

**Колонка:** `$table->string('slug')->unique()` (или `->nullable()->unique()`, если адрес можно не задавать).

**Проверка:** формат `^[a-z0-9]+(?:-[a-z0-9]+)*$`, не длиннее 255 символов, уникальность в таблице модели (записи в корзине тоже учитываются — у них остаётся уникальный индекс).

**В списке:** адрес как есть.

## Поведение с `from('title')`

Пока адрес пустой и его не правили вручную, он заполняется сам при вводе заголовка: «О компании» → `o-kompanii`. У сохранённой записи заполненный адрес при правке заголовка не меняется — ссылки на сайте не ломаются.

**Подробности:**

- транслитерация как у `Str::slug($text, '-', 'ru')`: пробелы и `_` становятся дефисами, другие знаки вроде `+` и `.` пропадают, `@` превращается в `-at-`;
- если поле очистить и сохранить, адрес построится из заголовка; занятый получит суффикс: `o-kompanii-2`, `o-kompanii-3`;
- адрес, который совпал с автоматическим (тем, что форма строит из заголовка сама), при занятости тоже получает суффикс, а не ошибку: сервер не отличает его от адреса, заполненного скриптом формы. Это работает и при сохранении через импорт и MCP;
- введённый вручную занятый адрес, не совпадающий с автоматическим, — ошибка «Такое значение поля «Адрес» уже есть».

| Метод | Что делает |
|---|---|
| `from('title')` | Поле, из которого строится адрес |
| `unique(false)` | Не проверять уникальность (например, адрес уникален только внутри родителя — задайте своё правило через `rules()`) |
| `maxLength(100)` | Наибольшая длина (по умолчанию 255) |

Общие методы — [README](README.md#общие-методы).

Адрес из любого текста в своём коде: `Slug::slugify('О компании')` → `o-kompanii`.
