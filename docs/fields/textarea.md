# Textarea

Многострочный текст без оформления. Переносы строк сохраняются.

```php
use Fastleo\Fields\Textarea;

Textarea::make('excerpt', 'Анонс')->rows(4)->maxLength(500);
```

**Колонка:** `$table->text('excerpt')->nullable()`.

**Проверка:** строка; с `maxLength()` — не длиннее заданного.

| Метод | Что делает |
|---|---|
| `rows(8)` | Высота поля в строках (по умолчанию 5) |
| `maxLength(500)` | Наибольшая длина (по умолчанию без ограничения) |

**В списке:** по умолчанию скрыт. С `showInList()` — первые 100 символов. На странице просмотра — полностью, с переносами строк.
