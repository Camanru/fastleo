# Список записей

Список раздела строится из тех же полей, что и форма. Столбец — каждое поле, видимое в списке.

## Какие поля видны

- Видны все поля, кроме длинного текста (`Textarea`, `Markdown`, `Code`, `RichText`), `Hidden`, `Password`, вложенных блоков и JSON-полей (`HasMany`, `HasOne`, `Repeater`, `Blocks`, `KeyValue`, `Seo`) и `BelongsToMany` — они скрыты по умолчанию.
- `hideInList()` — убрать столбец, `showInList()` — показать скрытый по умолчанию.
- `onlyInList()` — столбец есть, а в форме поля нет (например, `created_at`).
- Первый столбец — ссылка на запись (на форму, если её можно менять, иначе на просмотр).

```php
Text::make('title', 'Заголовок')->searchable()->sortable(),
Textarea::make('excerpt', 'Анонс')->showInList(),          // первые 100 символов
DateTime::make('created_at', 'Создано')->onlyInList()->sortable(),
```

Как поле выглядит в списке, меняют `formatUsing()` и `listView()` — [fields/README.md](fields/README.md). Статусы `Select`/`Enum` можно показать цветными метками: `->badges([...])` ([select.md](fields/select.md)). Столбец с подсчётом (число заявок, сумма продаж) — `->fromQuery()`, см. [«Вычисляемые столбцы»](#вычисляемые-столбцы).

## Поиск

Строка поиска появляется, если хотя бы одно поле отмечено `searchable()`. Ищется подстрока в любом из этих полей; символы `%` и `_` ищутся как обычные.

Ищется сохранённое значение: у `Select` — значение варианта (`published`), а не подпись; у дат — `2026-03-08`; у [многоязычного поля](translations.md) — текст на любом языке.

Регистр букв не важен во всех базах: «врач» найдёт «Врач». В MySQL это даёт обычная `_ci`-сортировка колонки (с бинарной `_bin` поиск различает регистр).

Для больших таблиц поиск по подстроке не использует индекс — отмечайте `searchable()` только нужные поля.

## Глобальный поиск

Кнопка «Поиск» в шапке или **Ctrl+K** (⌘+K на Mac) открывает окно поиска по всей админке. Он ищет:

- **пункты меню** — разделы, настройки, свои страницы — по названию;
- **записи разделов** — по тем же полям `searchable()`, что и поиск в списке. До пяти записей на раздел, в том порядке, в каком они идут в списке раздела.

Стрелки выбирают результат, Enter открывает его, Esc закрывает окно. Запись открывается на форме редактирования, а если менять её нельзя (Policy `update`, раздел только для просмотра) — на странице просмотра.

Что видит администратор, определяют права: раздел участвует, только если доступно `viewAny`, а каждая найденная запись проходит Policy `view`. Раздел можно исключить из глобального поиска, оставив поиск в его собственном списке:

```php
protected static bool $globallySearchable = false;
```

Строка поиска — от 2 до 100 символов; запросов не больше 60 в минуту. Адрес для своих клиентов: `GET /fastleo/search?q=…` (JSON `{groups: [{label, items: [{title, hint, url}]}]}`), доступен только вошедшему администратору.

## Фильтры

Фильтры описываются в методе `filters()` ресурса. Над списком появляется кнопка «Фильтры», под ней — панель: выбор сразу применяет фильтр, «Сбросить» убирает фильтры и поиск. Фильтры работают вместе друг с другом и с поиском.

```php
use Fastleo\Filters\BelongsToFilter;
use Fastleo\Filters\BelongsToManyFilter;
use Fastleo\Filters\BooleanFilter;
use Fastleo\Filters\DateRangeFilter;
use Fastleo\Filters\SelectFilter;
use Illuminate\Database\Eloquent\Builder;

public function filters(): array
{
    return [
        SelectFilter::make('status'),                    // варианты и подпись — из поля status
        BelongsToFilter::make('category_id'),            // рубрика — из поля BelongsTo
        BelongsToManyFilter::make('topics'),             // тема — из поля BelongsToMany
        BooleanFilter::make('is_published', 'Опубликовано'),
        DateRangeFilter::make('published_on', 'Дата публикации'),
        DateRangeFilter::make('created_at', 'Создано'),  // колонка без поля в форме
    ];
}
```

| Фильтр | Что делает |
|---|---|
| `SelectFilter` | Записи с выбранным вариантом. Варианты — из поля `Select`, `Enum` или `Radio` с тем же именем либо свои: `->options([...])` (массив, PHP enum или замыкание). Для `Select::multiple()` (json-массив) — записи, в массиве которых есть вариант |
| `BooleanFilter` | «Все / Да / Нет». «Нет» показывает и записи без значения (`NULL`) |
| `BelongsToManyFilter` | Записи, у которых среди связанных есть выбранная (темы статьи, услуги врача). Имя фильтра — имя поля `BelongsToMany` (метод связи модели); варианты, подписи и `query()` — из него, поиск по серверу — как у `BelongsToFilter` |
| `BelongsToFilter` | Записи, связанные с выбранной. Нужно поле `BelongsTo` с тем же именем: варианты, подписи и `query()` — из него (`dependsOn()` не учитывается). Если записей больше `fastleo.relations.preload`, список ищет по серверу |
| `DateRangeFilter` | Даты «с … по …», обе границы включительно, любую можно не указывать. У даты со временем (`DateTime`, `created_at`) день считается в часовом поясе админки |

Подпись — вторым аргументом `make()` или `->label()`; по умолчанию — подпись одноимённого поля.

Детали:

- `using()` у `DateRangeFilter` получает массив `['from' => ?string, 'to' => ?string]` (даты `Y-m-d`), а не строку.
- `SelectFilter` из `Select` с `dependsOn()` получает варианты для пустой зависимости.
- `DateRangeFilter` по колонке, которой нет среди полей и у которой нет каста `date`, считает значение датой со временем: границы дня сдвигаются на часовой пояс админки.

**Значение по умолчанию** — `default()`: список открывается уже отфильтрованным, например «только открытые», «менеджер — я», «вчера — сегодня». Значение — то, что выбрал бы администратор: вариант `Select`, `true`/`false` у `BooleanFilter`, id у `BelongsToFilter`, у дат `['from' => 'ГГГГ-ММ-ДД', 'to' => 'ГГГГ-ММ-ДД']`. Число, `BackedEnum` и `bool` пакет приводит к виду из адреса сам (`auth()->id()` → `'5'`, `Status::New` → его значение); замыкание вычисляется при каждом показе списка:

```php
SelectFilter::make('status')->default('new'),
BelongsToFilter::make('manager_id', 'Менеджер')->default(fn () => auth()->id()),
DateRangeFilter::make('created_at', 'Создано')->default(fn () => [
    'from' => today()->subDay()->toDateString(),
    'to' => today()->toDateString(),
]),
```

- Умолчание применяется, пока в адресе нет `filter[имя]`. Администратор выбирает «Все» (у дат — стирает обе границы): в адресе остаётся пустой `filter[имя]=`, и умолчание не действует. Кнопка «Сбросить» появляется, только когда вид списка отличается от того, что открывается без параметров (есть поиск, выбрано «Все» или другое значение); она ведёт на адрес без параметров, то есть возвращает умолчание.
- Фильтр в панели показывает значение по умолчанию выбранным; пока оно действует, список идёт простой таблицей — без дерева и ручного порядка, как при любом фильтре.
- Экспорт из списка берёт те же фильтры, что и сам список. В глобальном поиске (Ctrl+K) и в [MCP](claude.md#mcp-сервер) умолчания не применяются: они видят все записи.
- Значение не из вариантов не применяется, как и в адресе. Ничего не запоминается: ссылка на раздел всегда открывает одно и то же.

**Свой запрос** — `using()`: замыкание получает запрос и проверенное значение фильтра.

```php
SelectFilter::make('popular', 'Популярность')
    ->options(['yes' => 'Больше 1000 просмотров'])
    ->using(fn (Builder $query, string $value) => $query->where('views', '>', 1000)),

BooleanFilter::make('has_photo', 'С фото')
    ->using(fn (Builder $query, bool $value) => $value ? $query->whereNotNull('photo') : $query->whereNull('photo')),
```

**Свой тип фильтра** — наследник `Fastleo\Filters\Filter` с методами `value()` (проверить значение из адреса, `null` — фильтр выключен), `query()` (условие) и `view()` (Blade-шаблон: получает `$filter`, `$value` и `$form` — id формы списка для атрибута `form`).

Заготовка класса и шаблона (подключается в `filters()` ресурса как `ByCity::make('city', 'Город')` и `use App\Fastleo\Filters\ByCity;`):

```bash
php artisan fastleo:make-filter ByCity            # app/Fastleo/Filters/ByCity.php + resources/views/fastleo/filters/by-city.blade.php
```

**Безопасность.** Применяются только фильтры из `filters()`: колонка из адреса без фильтра игнорируется. Значение не из вариантов, массив вместо строки, несуществующая дата — фильтр не применяется, ошибки нет.

Пока включён фильтр, список идёт простой таблицей: без дерева и ручного порядка (как при поиске).

## Сортировка

Клик по заголовку столбца с `sortable()` сортирует по возрастанию, повторный — по убыванию. По остальным столбцам сортировать нельзя — имя колонки из адреса без `sortable()` игнорируется.

Порядок по умолчанию — новые записи сверху. Свой — в ресурсе:

```php
protected static ?array $defaultOrder = ['name', 'asc'];
```

## Страницы

По 25 записей на странице (`fastleo.list.per_page` в [настройках](configuration.md) или `$perPage` в ресурсе). Кнопка «Все» показывает весь раздел одной страницей, но не больше `fastleo.list.max_all` (1000) записей.

Под списком — выбор «На странице»: 25, 50 или 100 записей (`fastleo.list.per_page_options` или `$perPageOptions` в ресурсе, `[]` — выбора нет). В выбор всегда входит обычное число записей раздела (`$perPage`); число вне списка, например `?per_page=7`, игнорируется. Выбор появляется, когда записей больше, чем в самом малом варианте; он сохраняется при поиске, фильтрах и сортировке. В [связанных таблицах](related.md) выбор тот же (размеры берутся из дочернего раздела); при `Related::perPage()` первая страница — с этим числом, пока администратор не выбрал другое.

Поиск, фильтры, сортировка и страница хранятся в адресе (`?q=…&filter[status]=published&sort=title`) — ссылку на отфильтрованный список можно отправить коллеге.

## Ручной порядок

С `$sortColumn` в ресурсе ([resources.md](resources.md#ручной-порядок)) у строк появляются:

- стрелки «выше» / «ниже» — работают и на границе страницы (запись меняется местами с соседом с другой страницы);
- ручка для перетаскивания (в таблице; на телефоне — только стрелки).

Пока список отсортирован по столбцу, ищется, отфильтрован или открыта корзина, стрелок и ручки нет — порядок там другой.

## Дерево

С `$treeColumn` ([resources.md](resources.md#дерево)) список — дерево: отступы, сворачивание веток, число вложенных у записи (ссылка на ветку), кнопка «+» для вложенной записи. Перетаскивание в дереве — только внутри своего уровня; перенос в другую ветку — полем «Родитель» в форме. Страницы режут дерево по порядку обхода; ветка `?parent=ID` хранится в адресе.

## Действия над записью

Кнопка «Плотность таблицы» над списком переключает строки между обычными (52 px) и компактными (40 px); выбор запоминается в браузере администратора. Справа в строке (на телефоне — внизу карточки): открыть, изменить, удалить и меню «…» со [своими действиями](actions.md). Галочки слева выбирают записи для массовых действий: «Удалить», в корзине — «Восстановить» и «Удалить навсегда», и свои. Кнопки, на которые у администратора нет прав, не показываются — [authorization.md](authorization.md). В корзине — восстановить и удалить навсегда ([resources.md](resources.md#корзина)).

## Подсветка строк

Непросмотренные записи раздела с `$readColumn` выделены жирным сами — [отметка «просмотрено»](resources.md#отметка-просмотрено).


Строку списка можно подкрасить по состоянию записи: просроченная задача — красным, выполненная — зелёным. Метод `rowTone()` ресурса возвращает тон — `success`, `warning`, `danger`, `info`, `neutral` — или `null` (без цвета). Те же цвета у строк связанных таблиц ([related.md](related.md)).

```php
use Illuminate\Database\Eloquent\Model;

public function rowTone(Model $record): ?string
{
    // done_at и due_at — колонки с кастом `datetime` в модели
    return match (true) {
        $record->done_at !== null => 'success',
        $record->due_at?->isPast() => 'danger',
        default => null,
    };
}
```

Цвет виден и в таблице, и в карточках списка на телефоне. Цвет — только подсказка: статус должен быть виден и текстом (`->badges()` у `Select`/`Enum`). Неизвестный тон — `LogicException`, а не молчаливый пропуск.

## Правка в ячейке

Цена, статус, количество меняются прямо в списке, без открытия формы: `->inlineEditable()`. Щёлкнули по ячейке, изменили, ушли из поля (или нажали Enter) — значение сохранилось; Escape возвращает прежнее. Ошибка проверки показывается под полем, а в нём остаётся прежнее значение.

```php
Number::make('price', 'Цена')->min(0)->inlineEditable(),
Enum::make('status', 'Статус')->enum(OfferStatus::class)->inlineEditable(),
BelongsTo::make('manager_id', 'Менеджер')->inlineEditable(),
```

- Подходят однострочный текст (`Text`, `Email`, `Tel`, `Url`; `Slug`, `Textarea`, `Markdown` и `RichText` — нет, поле бросит ошибку описания), число, список с одиночным выбором (`Select`, `Enum`, `Radio`) и `BelongsTo`; для галочки есть [быстрый переключатель](fields/toggle.md#быстрый-переключатель-в-списке). У `BelongsTo` вариантов должно быть не больше `fastleo.relations.preload`, иначе ячейка остаётся обычным текстом.
- Запись идёт так же, как из формы: право `update` на запись, поле видно и не `readonly()`, правила поля (`required()`, `min()`, `maxLength()`, свои `rules()` — с остальными значениями записи в данных), Eloquent, observers и [журнал изменений](activity.md). Правила других полей не проверяются: старая запись, не проходящая чужое правило, не мешает править ячейку.
- Поле не должно зависеть от других полей формы (`dependsOn()`, `visibleWhen()`) и они — от него; также нельзя вместе с `multiple()`, `translatable()` и `fromQuery()`. Иначе при описании раздела будет ошибка: значения полей разошлись бы.
- Работает в списке, на телефоне (карточки) и в [связанных таблицах](related.md). В корзине и без права `update` ячейка — обычный текст. У первого столбца пропадает ссылка на запись.
- Список с цветными метками (`badges()`, `Enum` с `tone()`) красится в цвет метки выбранного варианта.
- После сохранения [вычисляемые столбцы](#вычисляемые-столбцы) этой строки (маржа, сумма заявки) пересчитываются и обновляются на странице сами; итоги и порядок сортировки обновит перезагрузка (или [автообновление](#автообновление-списка)).

## Вычисляемые столбцы

Число заявок клиента, выручка, дата последнего заказа берутся не из колонки таблицы, а из запроса. Посчитайте их в `query()` ресурса (`withCount`, `withSum`, `withMax` или подзапрос с псевдонимом) и опишите поле с этим именем и `fromQuery()`:

```php
public function query(Builder $query): Builder
{
    return $query->withCount('offers')->withSum('soldItems as revenue', 'price');
}

public function fields(): array
{
    return [
        Text::make('title', 'Клиент')->searchable()->sortable(),
        Number::make('offers_count', 'Заявок')->fromQuery()->sortable(),
        Number::make('revenue', 'Выручка')->fromQuery()->sortable()->formatUsing(fn ($v) => number_format((float) $v, 0, ',', ' ').' ₽'),
    ];
}
```

Такое поле только для показа: оно есть в списке, на странице просмотра, в выгрузке и в ответах MCP; в форме, импорте, записи через MCP и журнале изменений его нет, а `fastleo:doctor` не ищет для него колонку (но предупредит, если `query()` не отдаёт значение с таким именем). По заголовку можно сортировать — сортировка идёт по псевдониму. Искать (`searchable()`) и фильтровать по такому столбцу нельзя: поиск и фильтры работают по колонкам таблицы. Подходят простые типы: текст, число, дата, время, список, галочка, цвет; связи, файлы и визуальный редактор (`RichText`) — нет; `Markdown` и `Code` подходят как текст.

## Автообновление списка

Входящие заявки, заказы, очередь задач: чтобы новые записи появлялись без перезагрузки страницы, задайте разделу период в секундах:

```php
protected static ?int $poll = 10; // от 5 до 3600; null — не обновлять
```

Раз в `$poll` секунд страница запрашивается заново, и таблица подменяется, если в ней что-то изменилось (поиск, сортировка, страница и фильтры сохраняются). Обновление пропускается, пока:

- вкладка не видна;
- выбраны записи или открыто окно действия, меню записи;
- администратор печатает в ячейке ([правка в ячейке](#правка-в-ячейке)) или в поле поиска;
- идёт сохранение ячейки;
- в связанной таблице раскрыта строка ([related.md](related.md#раскрывающиеся-строки)) — такая таблица остаётся как есть, пока строку не закроют.

Так что набранное не пропадёт, а выбор записей не собьётся. [Связанные таблицы](related.md) на странице записи обновляются с периодом `$poll` своего (дочернего) раздела.

Каждое обновление — обычный запрос к странице (с запросом списка), поэтому не ставьте секунды без нужды; открытая и видимая вкладка продлевает сессию администратора, как и колокольчик уведомлений.

## Большие таблицы

Список рассчитан на сотни тысяч записей: страница — несколько запросов к базе, их число не растёт с размером таблицы. Чтобы так и оставалось:

- добавьте индексы на колонки, по которым сортируют (`sortable()`) и фильтруют, и на внешние ключи (`foreignId()->constrained()` создаёт индекс сам):

  ```php
  $table->string('status', 20)->default('draft')->index();
  $table->date('published_on')->nullable()->index();
  ```

- поиск `searchable()` ищет подстроку (`like '%…%'`) и индексом не ускоряется — на таблицах в сотни тысяч строк отмечайте `searchable()` одно-два коротких поля (заголовок, email), а не тексты;
- кнопка «Все» на 1000 записей рисует страницу заметно дольше обычной (секунды) — `fastleo.list.max_all` можно уменьшить.
