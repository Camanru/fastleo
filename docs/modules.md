# Готовые модули сайта

Команда `fastleo:module` копирует в сайт готовый раздел админки: страницу настроек, модель, миграцию, ресурс, виджеты главной страницы. **Публичную часть сайта (вёрстку, шаблоны, страницы) модули не создают** — её делает сайт сам. С этого момента код принадлежит сайту: его правят под себя, обновление fastleo его не трогает.

```bash
php artisan fastleo:module            # список с галочками
php artisan fastleo:module contacts   # без вопросов (для Claude и CI)
```

## Что делает команда

- Сначала проверяет всё: файлы, таблицы и адреса сайта, которые займёт модуль. Адрес занят, если у сайта есть маршрут с таким адресом или под ним (`leads` и `leads/{id}`); для `leads` важен метод — занятым считается только `POST`, обычная страница `GET /leads` не мешает. Модуль `news` адресов сайта не занимает. Если что-то занято, **не записывается ничего**; команда печатает список занятого. Чужой код не перезаписывается, ключа `--force` нет — снимите модуль с выбора или освободите место.
- Миграции получают текущую метку времени в имени, `App` в заготовках заменяется пространством имён приложения.
- Если модуль добавляет маршрут (сейчас только `leads`), в конец `routes/web.php` один раз дописывается подключение всех файлов `routes/site/*.php` (с пометкой `// fastleo: маршруты готовых модулей`).
- Тесты модулей (`tests/Feature/Site/…`) копируются, только если на сайте есть Pest: `pestphp/pest` в `composer.json` и файл `tests/Pest.php` (его создаёт `vendor/bin/pest --init`; без него тесты не знают про Laravel и падают). Иначе команда напомнит, где они лежат.
- Виджеты модуля дописываются в `widgets()` класса `Dashboard` (`app/Fastleo/Dashboard.php`); если класса нет, он создаётся (как `fastleo:make-dashboard`). Повторная установка не дублирует виджеты. Если `Dashboard` устроен необычно и конец списка не найден, команда ничего не меняет и печатает строки, которые нужно дописать самим.
- В конце печатает список созданных файлов.

## Модули

| Имя | Что получит сайт |
|---|---|
| `contacts` | Страница настроек «Контакты» (`app/Fastleo/ContactsSettings.php`): телефон, почта, адрес, часы работы. На сайте — `fastleo_setting('contacts.phone')` и другие ключи |
| `pages` | Раздел «Страницы» (`PageResource`, адрес в админке `site-pages`): дерево с ручным порядком, заголовок, адрес, «Опубликована», «В меню сайта», «Главная», содержимое из блоков (текст, картинка, галерея, призыв), SEO. Модель `Page` со скоупом `published()`. Подробнее — [ниже](#страницы) |
| `news` | Раздел «Новости» (`NewsResource`, адрес `news`): заголовок, адрес, дата публикации, «Опубликована», обложка, анонс, текст (RichText), SEO; виджет «Последние новости». Модель `News` со скоупом `published()`. Дата публикации в будущем откладывает показ до этой даты (в `published()`), пустая дата — показывать сразу |
| `leads` | Раздел «Заявки» (`LeadResource`, адрес `leads`): имя, телефон, почта, сообщение, страница-источник, статус (`LeadStatus`: новая, в работе, выполнена, спам); виджеты «Новые заявки» и график за 30 дней. И приём заявок с сайта — `POST /leads` с защитой от ботов. Подробнее — [ниже](#заявки) |

## Страницы

Модуль даёт данные и раздел админки; показ страниц на сайте — ваш. Пример (маршрут, который проверяется последним, чтобы не перехватывать остальные адреса сайта):

```php
// routes/web.php (после остальных маршрутов)
use Illuminate\Http\Request;

Route::fallback(function (Request $request) {
    $page = null;

    foreach (explode('/', $request->path()) as $slug) {
        $page = \App\Models\Page::query()->published()->where('slug', $slug)->where('parent_id', $page?->id)->first();
        abort_if($page === null, 404);
    }

    return view('pages.show', ['page' => $page]);
});
```

```blade
{{-- resources/views/pages/show.blade.php --}}
<x-fastleo::seo :model="$page" :title="$page->title" />
<h1>{{ $page->title }}</h1>
<x-fastleo::blocks :blocks="$page->content" />
```

- Слаг уникален во всей таблице; адрес вложенной страницы — слаги родителей и её собственный (`about/team`). Главная — страница с отметкой «Главная»: `Page::query()->published()->where('is_home', true)->first()`.
- Шаблоны блоков (`text`, `image`, `gallery`, `cta`) пишите сами: `resources/views/blocks/{тип}.blade.php` ([блоки](blocks.md)). **Пока шаблона блока нет, `<x-fastleo::blocks>` выводит пустоту** — страница покажет только заголовок. Ссылку блока «Призыв» (`url`) выводите, только проверив начало (`/` или `http(s)://`): значение вводит администратор, но `javascript:` в ссылку попадать не должно.
- Запасной маршрут в группе `web` стартует сессию на каждый несуществующий адрес (`/wp-login.php`, `/.env` — их перебирают боты): на сайте с большим посещением храните сессии в Redis (`SESSION_DRIVER=redis`) и задайте небольшой `SESSION_LIFETIME`.
- **Примеры.** `php artisan db:seed --class=PageSeeder` создаёт «Главную» и «О компании». Фабрика — `Page::factory()`.

## Заявки

Модуль даёт обработчик `POST /leads` (`LeadController`, `StoreLeadRequest`, маршрут в `routes/site/leads.php`) и раздел админки. **Форму рисует сайт.** Ей нужны поля `name`, `phone`, необязательные `email` и `message`, скрытая ловушка `leave_empty` и скрытое поле `form_token`:

```blade
<form method="post" action="{{ route('site.leads.store') }}">
    @csrf
    <input type="hidden" name="form_token" value="{{ \App\Http\Requests\StoreLeadRequest::token() }}">
    <div style="position: absolute; left: -9999px;" aria-hidden="true">
        <input type="text" name="leave_empty" tabindex="-1" autocomplete="off">
    </div>

    <input name="name" value="{{ old('name') }}" required>
    <input name="phone" value="{{ old('phone') }}" required>
    <button>Отправить</button>

    @error('name') {{ $message }} @enderror
    @error('form_token') {{ $message }} @enderror
    @if (session('lead_sent')) Спасибо! @endif
</form>
```

После отправки посетитель возвращается на ту же страницу (`back()`); успех — `session('lead_sent')`, ошибки — стандартные `@error`. Хотите форму в конструкторе страниц — добавьте тип блока в `PageResource` и шаблон блока с этой формой:

```php
Block::make('lead_form', 'Форма заявки')->icon('inbox')->fields([]),
```

- **Защита от ботов без внешних сервисов.**
  - Скрытое поле-ловушка `leave_empty` и зашифрованная метка времени показа формы (`form_token`), привязанная к сессии посетителя: метку, снятую с другой сессии, обработчик не принимает. Заполненная ловушка, пропавшая или подделанная метка — бот: он получает тот же ответ «Спасибо!», но заявка не сохраняется. Если метка настоящая, но выдана другой сессии (у живого посетителя между показом формы и отправкой сменился номер сессии — вход или выход на сайте), он видит ту же ошибку, что при слишком быстрой отправке, и может отправить форму ещё раз. Страницу с формой не кэшируйте целиком (полностраничный кэш, CDN «кэшировать всё»): метка и CSRF-токен в ней будут чужими, посетитель получит ошибку 419, а метка устареет.
  - Форма, отправленная быстрее чем через 3 секунды или спустя больше суток (долго открытая вкладка, автозаполнение браузера), ботом не считается: посетитель видит ошибку «Форма отправлена слишком быстро или страница устарела» с сохранённым вводом и может отправить ещё раз.
  - Не больше 5 заявок за 10 минут с одного адреса (`throttle:5,10,leads` — счётчик только у этого маршрута, потом 429). **За прокси** (Cloudflare, nginx, tunnel) настройте `trustProxies` ([безопасность](security.md)): иначе все посетители выглядят как один адрес и лимит станет общим на весь сайт: пять запросов одного недоброжелателя закроют форму для всех на 10 минут.
  - Нужна капча — добавьте проверку в `StoreLeadRequest::isBot()`.
- **Что приходит с формы.** Только имя, телефон, почта и сообщение; статус, отметка «просмотрено» и источник задаются кодом (`LeadController`), посетитель их подделать не может. Источник — путь страницы из заголовка `Referer`.
- **Уведомление.** Уведомления о заявках уходят не чаще 20 в минуту со всего сайта (общий потолок против пула адресов): сверх него заявка сохраняется и видна в разделе, но без уведомления. О новой заявке администраторы узнают из колокольчика (`Fastleo::notifyAdmins()`; колокольчик нужно [включить](notifications.md#как-включить-колокольчик)); если уведомление не ушло (почта, бот недоступны), заявка всё равно сохранена, посетитель видит «Спасибо», а сбой попадает в лог; включённые почта и боты ([уведомления](notifications.md)) получат её тоже. В списке непросмотренные заявки выделены, их число стоит в меню ([отметка «просмотрено»](resources.md#отметка-просмотрено)).

## Подогнать модуль под сайт

Модуль — **стартовый код сайта**, а не зависимость: файлы копируются в ваш `app/` один раз, обновлений и точек расширения у них нет, правьте их как свои. Что менять чаще всего:

- **Поле в заявке** (`leads`): колонка в миграции, поле в `$fillable` модели `Lead`, правило в `StoreLeadRequest::rules()`, значение в `LeadController::store()`, поле в `LeadResource::fields()`. Поля, которые посетитель не должен ставить сам (статус, менеджер, utm-метки с сервера), задавайте в контроллере.
- **Статусы** (`LeadStatus`, `leads`): меняйте `enum` и фабрику; в `LeadResource` цвета и подписи берутся из `badges()`/`tone()` enum.
- **Другая модель данных** (новости со статусами вместо «Опубликована»): модуль даёт 10 минут экономии на каркасе. Сделайте новую миграцию `alter`, перепишите ресурс, модель и фабрику, удалите сидер модуля (`NewsSeeder`) и строку виджета в `app/Fastleo/Dashboard.php`.
- **Страница настроек «Контакты»**: если на сайте уже есть своя страница настроек, модуль `contacts` не ставьте — две страницы с телефоном запутают редакторов.
- **Тесты модулей** копируются только в сайт с Pest. На сайте с PHPUnit проверку формы заявки напишите сами: токен привязан к сессии посетителя и содержит время показа формы, поэтому тест сам делает метку: задаёт cookie сессии (`$this->withCookie(config('session.cookie'), $sessionId)`) и отправляет `form_token` = `Crypt::encryptString((now()->timestamp - 5).'|'.$sessionId)`. Готовый образец — `vendor/camanru/fastleo/stubs/modules/leads/tests/Feature/Site/LeadsTest.php.stub`.

## Миграции

Модули `pages`, `news` и `leads` кладут в `database/migrations` свои миграции (метка времени в имени — момент установки). Таблиц ещё нет, пока вы не выполните `php artisan migrate`; `fastleo:install` делает это за вас по вашему «да» или с `--setup`, а `fastleo:module` об этом напоминает. Миграции модулей не зависят друг от друга. Если в базе уже есть таблица с таким именем (`pages`, `news`, `leads`), модуль не ставится.

## Как убрать модуль

Модуль — обычные файлы сайта: удалите те, что перечислила команда при установке (список также виден в `git status`), и таблицу, если модуль её создавал (`php artisan migrate:rollback` для миграции модуля или `Schema::drop`). Кроме файлов, модуль оставляет следы в двух местах:

- **`app/Fastleo/Dashboard.php`** — строки виджетов в `widgets()`: `news` — «Последние новости» (`Table`), `leads` — «Новые заявки» (`Stat`) и «Заявки за 30 дней» (`Chart`). Удалите их, иначе главная страница админки упадёт без модели.
- **`routes/web.php`** — блок с пометкой `// fastleo: маршруты готовых модулей` (подключает `routes/site/*.php`). Он общий для всех модулей: уберите его, только когда в `routes/site/` ничего не осталось.

| Модуль | Файлы |
|---|---|
| `contacts` | `app/Fastleo/ContactsSettings.php` |
| `pages` | `app/Models/Page.php`, `app/Fastleo/PageResource.php`, миграция `*_create_pages_table.php`, `database/factories/PageFactory.php`, `database/seeders/PageSeeder.php`, `tests/Feature/Site/PagesTest.php` |
| `news` | `app/Models/News.php`, `app/Fastleo/NewsResource.php`, миграция `*_create_news_table.php`, `database/factories/NewsFactory.php`, `database/seeders/NewsSeeder.php`, `tests/Feature/Site/NewsTest.php`, виджет в `Dashboard.php` |
| `leads` | `app/Models/Lead.php`, `app/Enums/LeadStatus.php`, `app/Fastleo/LeadResource.php`, `app/Http/Controllers/LeadController.php`, `app/Http/Requests/StoreLeadRequest.php`, `routes/site/leads.php`, миграция `*_create_leads_table.php`, `database/factories/LeadFactory.php`, `tests/Feature/Site/LeadsTest.php`, виджеты в `Dashboard.php` |
